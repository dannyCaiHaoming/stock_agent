# Roadmap

最后更新：2026-10-20。2026-10-12 的原始规划与逐日进度见 [roadmap-history.md](roadmap-history.md)。

## 目标与原则

- 产品：美股与 ETF 的研究与投资决策 Agent Package（仅研究建议，券商永久只读）。两宿主：Claude Code、Codex；免费数据；动作集 BUY/ADD/HOLD/REDUCE/EXIT/NO_TRADE。
- 分工：LLM 负责研究、解释与判断；Python 只负责数据、确定性计算、校验与持久化。
- 能力增强靠 Skill 与共享 references（方法卡、案例卡、统计卡），不是更新模型参数。
- 新资料先检验、再接入：每类资料先建事件表、按“当时已知”统计（同日对照、整群置信区间），有区分力才写进方法卡；没有证据前只作背景。
- 版本冻结：评估只用冻结版本（当前 `research-v3`，见 [frozen-versions.md](frozen-versions.md)）；修改进入下一个版本。历史回放样本只用于说明，不再用于调参。

## 已验证的结论（截至 2026-10-19）

- 流程结构（三方审查、备忘录交锋）、判断问题（改问基本面方向）、模型能力（gpt-6.1-sol）都没有带来方向预测上的可靠改善；新流程与 B 在 27 个回放样本上无可靠差异。见 `evals/replay/ablation/27-codex-summary.md`。
- 7 个单一信号（趋势阶段、均线多头、营收加速/放缓、利润率扩张/收缩）相对同日对照的优势尚未证实；stage 2 的 60 日 +0.91pp 方向偏正但置信区间含 0。见 `evals/signals/audit-latest.md`。
- 议员交易、内部人、13F、新闻**尚未做过统计检验**；此前“没有作用”的说法只来自 LLM 复盘，不成立为结论。议员整体买入中位跑输 SPY，但少数议员的历史记录明显更好（`evals/replay/congress-leaderboard-2025-01-01.md`），需要按事件检验。
- 免费数据没有历史一致预期与历史社交情绪，这两类只能从现在开始自行积累。

## 待办（按优先级）

### P1 从现在开始积累的数据（越早开始越有价值）
1. **分析师一致预期每日快照**：股票池每天记录 Yahoo 的 EPS/营收预期、预期趋势与修正家数、目标价；几个月后形成自己的预期历史，用于“预期上修/下修”“业绩超预期”信号。
2. **社区情绪每日快照**：moomoo 社区情绪与 Stocktwits 公开消息流（先确认使用条款）；X 的历史数据免费渠道不可得。

### P2 事件研究：把“看概率”做成统计卡（全部用历史数据，按当时已知过滤）
3. **8-K 事项代码事件表**：按 SEC 8-K 的 Item（2.02 业绩、5.02 高管变动、1.01 重大协议、2.01 完成收购、3.02 增发、7.01/8.01 其他等）统计事件后 1/5/20/60 日的上涨概率与相对同日对照的差值。
4. **议员交易信号**：以申报公开日为起点，按条件分组——截至当时历史胜率靠前的议员、买入 vs 卖出、金额区间、股票 vs 期权、多位议员同期买入。
5. **内部人信号**：30 天内多位高管公开市场买入（排除 10b5-1 计划）、CEO/CFO 买入、大额买入；对照单人小额买入。
6. **13F 信号**：跟踪基金的新建仓、大幅加仓、清仓（以申报日为起点）。
7. **新闻标题分类事件表**：把 GDELT 标题按类型归类（评级上调/下调、业绩超预期/不及预期、指引上调/下调、诉讼调查、并购、产品发布、高管变动等），先规则后 LLM 分类并抽查准确率，再统计各类事件后的概率。
8. **财报新闻稿时点的基本面信号**：起点从 10-Q 受理日改为 8-K 业绩新闻稿发布时间（只用当时已披露的数据）。
9. **公司指引数据集**：从历次 EX-99.1 抽取指引数字（LLM 抽取 + 程序核对），统计“超出自身指引”“指引上调/下调”的效果；这只能称为“相对公司指引的意外”，不能称为“超出市场预期”。

### P3 待探测的资料
10. 财报电话会议纪要的合规免费来源（文字最能发挥 LLM 的阅读能力）。
11. 行业与商品数据（FRED、EIA 等免费序列；存储芯片价格等专业数据多为付费）。
12. FINRA 空头持仓（每两周，免费）。

### 接入方式
- 每一项先产出统计卡（与现有 `get_signal_stats` 同一口径），有区分力的再写进方法卡；完成一批后冻结为 `research-v4`。

### 暂缓（用户决定）
- 前瞻验证、每日操作的连续持仓模拟、阶段 3 真实组合、阶段 6 交易反思、快层（每日盯盘，按仓位类型区分核心仓与交易仓）。
