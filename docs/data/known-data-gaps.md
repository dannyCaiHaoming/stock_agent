# 已知数据缺口（免费来源无法修复）

记录日期：2026-10-13。来自第 1 阶段两宿主实跑报告的“数据缺口”排查。可修复的缺口（字段映射、8-K 附件、全文搜索、TTM EPS 近似等）已在 stock-data 工具中修复；以下为当前免费数据源的固有限制，报告中应标为 `SOURCE_UNSUPPORTED` 并说明影响，不得用记忆或推测补数。

| 缺口 | 影响 | 现状与可能的后续来源 |
|---|---|---|
| 分析师预期历史修正序列 | 中：无法重建预期下修/上修的时间线 | Yahoo 只有当前快照与 7–90 日 EPS 趋势、修正次数。OpenD 的 `analyst-consensus`/评级汇总可能补充，需实测其是否含历史 |
| 大宗商品现货价格历史（如锂、铜、原油现货） | 中（周期股特有）：价格驱动只能间接判断 | 免费源与 OpenD 均无现货历史；以公司披露的实现价格、销量与指引替代，并在报告中说明 |
| 法说会逐字稿 | 中：管理层口头指引与问答无法核对 | 免费源没有；以 8-K 新闻稿（EX-99.1）、10-Q MD&A 与公司公告代替 |
| 社区情绪样本量与相关性 | 低：仅作第三方参考展示 | moomoo `stock_feed` 为实时 feed，样本少且混有无关帖子；不量化、不参与判断 |
| 新闻关键词误中（同名、近似名公司） | 低 | moomoo 新闻搜索按关键词匹配；报告只保留可确认为目标公司的条目 |
| 财报发布日期 | 低 | Yahoo 为估算；以公司 IR 公告或 8-K 交叉确认 |
| 第三方异动数据时间戳异常（偶见晚于决策日） | 低 | 来自 moomoo 异动接口；晚于截止点的条目不采用并注明 |
| 期权历史 OI、日内数据、非美市场 | 中 | 不在第 1 阶段范围；期权 IV 历史等可经 OpenD 获取，见第 2/5 阶段 |
