## Purpose

让单只美股普通股在明确的历史决策时点，依据当时可核验的资料生成冻结的条件化建议，再隔离读取后续行情评价建议表现；保留数据版本、模型知识和模拟持仓带来的限制，供逐样本复盘。

## ADDED Requirements

### Requirement: 历史回放必须明确股票、时点、期限与假设持仓
每次回放 SHALL 输入受支持普通股的稳定身份、带时区的 `decision_cutoff`、预先确定的评价期限/基准、以及 `FLAT` 或 `HELD` 的假设持仓状态。假设状态只决定哪些动作有语义，不代表用户真实账户；缺失或身份不符的输入 MUST 在模型前拒绝。不同截止点的资料和建议 MUST 分别冻结并保留独立运行身份。

#### Scenario: 空仓样本请求减仓
- **WHEN** 回放的假设状态为 `FLAT`，CIO 草案却输出 `TRIM` 或 `EXIT`
- **THEN** 建议契约拒收该动作，不填造历史持仓

#### Scenario: 同一股票两个历史时点
- **WHEN** 用户选择同一股票的两个截止点
- **THEN** 两次运行分别绑定各自可得事实、研究报告、模型版本与建议，不用第二次资料改写第一次结果

### Requirement: 未来结果必须在建议封存后独立评价
系统 MUST 在建议、来源证据、模型/Skill/Schema/策略版本及输入 hash 封存后，才向确定性评价步骤开放截止点之后的价格、基准和公司行动。正向、Skeptic、CIO 的模型工具与 Prompt MUST 不可访问结果数据。评价 SHALL 按预先固定的时间窗与价格口径比较单股和基准，记录评价口径、有效观测、限制及样本数量；无价格、公司行动口径不明、期限尚未结束或成交假设不足时 MUST 输出 `NOT_EVALUABLE` 和原因，不编造收益或胜率。

#### Scenario: 建议生成时有未来价格文件
- **WHEN** 外置运行目录中已有决策截止点之后的行情
- **THEN** 研究阶段不能读取它；只有封存的建议与研究证据通过校验后，评价步骤才可使用

#### Scenario: 股票在期限内发生拆股
- **WHEN** 评价价格需要拆股调整，但调整口径或公司行动记录不足
- **THEN** 该指标明确不可评价或限定范围，不将未经核实的普通收盘价差当总收益

### Requirement: 历史回放必须保留方法限制并避免样本倒调
回放 SHALL 明示其资料模式为当时已捕获快照或事后可核验的历史重建，并记录哪些数据集无法证明历史 vintage。由于当前 LLM 可能已知截止点后的事件，报告 MUST 说明无法完全消除模型记忆中的未来信息，不能称为无前瞻信息的实盘回测。样本日期、评价期限、基准和版本 MUST 在查看结果前锁定；系统不得根据同批结果自动修改 Prompt、风险策略或生产文件。

#### Scenario: 回放建议事后表现不佳
- **WHEN** 某预先选定样本的后续表现与建议不符
- **THEN** 保留原建议和结果，允许提出人工审阅的改进假设，不重写该历史建议或选择性剔除样本
