### 3. OpenD 语义修复保持局部

- wrappers 使用具名参数；绑定当前 SDK 的市场枚举、时间字段和分页类型。错误响应仍保持对应能力隔离。
- Morningstar 区分一份报告和内部章节/列表；初始界限为最多 16 个受支持章节、每个观点列表最多 20 项、总正文响应不超过既有 4 MB。按实际响应校准窄规则，不统一放大所有方法 max_rows。读取 `context` 和嵌套更新时间；缺时间按当前观察处理并标限制，不借总体报告日期伪造章节发布时间。正文通过现有 Evidence/研报接缝进入模型，附章节定位和 hash，标题继续 LEAD_ONLY。
- 机构期间起止保留为 period 字段，事实可知时间使用可核实供应商更新时间或真实观察时间；未结束季度标 provisional，不改成虚构结束日。未来供应商时钟值保留在诊断，不能截断成看似有效的历史事实；坏行逐项排除，有效行继续，全部无效才返回无证据。
- 期权只对当前已选合约（仍最多三个到期日、48 个合约）的关键缺项补 OpenD，不新增第二轮择约。身份包括标的、到期日、行权价、类型及合约调整；复用已知合约属性，未知乘数不默认 100。Yahoo 比例 IV 与 OpenD 百分比 IV统一到既定规范单位，原值/转换可追溯。两源证据并列保留，不让股票最新价时间覆盖 OI/Greeks 的观察时间。

### 4. 同行只增加资料对象，不增加持仓或研究 Agent

沿用现有 Market Catalyst 同行选择，最多三个候选；身份核实后，向现有逐证券采集/Memory 接缝传入最小证券描述。不得伪造用户确认的 Handoff 来调用持仓入口。确需抽取共用函数时只抽取现有确定性按证券流程，不建立新的采集框架。

同行默认采集身份、可比财务、日线、业务分部和有界研究线索；不因多一个同行自动采集其全部期权、内部人或重新请求共享宏观。完整来源授权的证券数/请求数仍受限。行业 selector 按目标及选定同行 security_id + 显式数据集接收资料，避免把其他股票全量内容混入。

复用稳定 `RESEARCH_MEMORY_ROOT` 和其 raw-cache；修正同行路径在未显式 LIVE_CACHE_ROOT 时退回临时 bundle/cache 的不一致。按既有 dataset 计划/提交/View 保存归一化资料；选择关系只记录本次比较用途。跨 ticker 重复、同 ticker 多任务、版本不兼容、坏数据失败均沿用既有幂等和 checkpoint 规则。新增快照只在用户触发研究时积累，本 Change 不启动后台定时抓取。

### 5. 窗口和取证只做有界补齐

- 日线：按所需交易日从锁定日历计算范围并留有限缓冲，默认初始化上限 550 个自然日；若仍不足，最多一次在此上限内补洞，不循环扩展。日历必须覆盖实际请求；已有长历史不截短，后续按缺口增量。历史两年回测窗口由另一个 Change 定义。
- SEC：优先复用已下载正文，按期间选择支持比较的申报；本轮每证券最多新增两份必要 filing/业绩附件正文，沿用来源总预算。客户/供应商关系仅抽取明确段落作为原文事实，不构建知识图谱，不确定性识别匿名客户。
- 宏观：复用已接入八个指标与官方主源；如活动/通胀问题仍缺，至多从真实指标目录核实新增 GDP/核心 PCE 两项，不猜 ID、不增加来源。每序列最多 24 条观测，缺历史 vintage 仍如实保留。
- 日历、机构、内部人、期权历史：默认日历窗口为截止点前后各 30 日（未来日程仅作已公告事件），内部人覆盖最近 90 日，期权标的历史沿用最近 30 日，机构目标为最近两个已结束可比期间并单列当期临时观察。每请求族最多三页（含首页），且仍受既有方法/证券/批次预算与已批准记录上限约束；仅在该窗口或两期比较未覆盖时翻页。游标重复立即停止并记录。若 method manifest 现仅允许一次，按方法显式版本化到本预算，不能隐藏绕过。
- 新闻 Skill 已有公开 endpoint adapter 继续复用：每证券 ticker/公司名各最多一次、每次 10 项；不动态执行第三方 Skill 或扩散到任意文章站点。全文边界保持已批准来源。
- `RESEARCH_MATERIALS_ARTIFACT_REF_INVALID` 先复现实际返回路径/声明路径首个差异；修正工具提示或当前 invocation 相对引用，并保留未知、跨 invocation、路径逃逸、文件不存在及 hash 失败的拒绝。沿用原 Agent 有界纠正，Python 不代写研究正文。

### 6. 同一批次与下游兼容

第三轮材料市场任务的实际 Hook 输入为 1,386,731 UTF-8 字节、5,732 条目录元数据，其中 MRVL/SPY 日线 4,550 条。资料准备直接使用 `_facts_for_capability`，漏用了正式市场路径已有的每序列最近两条限制；目录没有事实值且本模式无 Evidence 查询权限。此为已复现的输入膨胀缺陷，与第四项启动后无工具结果相关，但尚无模型服务错误证明它是超时的唯一原因。市场资料准备复用既有 `_bounded_latest_facts`，完整 Gate 保持不变；所有材料任务实际紧凑 Hook JSON 在 prepare 和模型启动前校验不超过既有 256 KiB 边界，Hook 使用同一序列化函数。超限在模型前报具体错误，不截断 JSON、不丢弃 Gate 事实、不改研究输出契约。采用同一 v10 Gate 零模型重建，核对市场目录 5,732→113、上下文实际字节数和全 Gate 内容一致，再决定真实补测。

资料准备/同行选择使用准备阶段已有合法输入；同行、增强资料获取完成后建立最终共同 cutoff，再冻结八维包。所有视图、报告、provider audit 与 dispatch 绑定最终 Gate，不能只取多个时间的 max 后跳过统一校验。显式历史 cutoff 不推进。

同行合并 Gate 的 cutoff 晚于原始 live 采集时，原 `data-preparation.json` 和逐股 capture batch 不改写时间、不搬作新采集。正式八维准备显式接收原始 Gate 路径，验证其内容 hash 等于合并 Gate 的 `base_gate_content_hash`、run/source bundle 一致、原 cutoff 不晚于最终 cutoff；原 preparation 仍须通过自身 hash、READY 和原 cutoff 校验，batch Evidence ID 再逐项与最终 Gate 允许目录相交核对。缺原 Gate、路径错配或证据在最终 Gate 被排除均在启动八维模型前拒绝。宿主入口仅将原 Gate 作为受限的批次绑定输入，不更换最终 Gate/最终 View，也不重写历史事实时间。

保留现有 Agent identity、角色隔离、Schema/PIT/Evidence 门禁和宿主入口；必要 schema/适配版本以新增版本及历史兼容读取处理，不修改旧产物。Skeptic/CIO 的输入兼容用确定性校验检查，不为本需求自动启动下游模型。

### 6.1 正式八维档案包装与按需读取

正式八维与材料准备是不同的交付路径。本次冻结包的八维初始紧凑 JSON 合计 4,210,414 字节，其中 provider coverage 为 2,416,173 字节；基本面 930,309 字节的大部分为审计、目录和重复 ID，而非正文。只读方案测量得到：覆盖摘要约 1,820,296 字节，叠加重复列表/格式枚举消减约 1,166,965 字节，再用表头一次的目录行表示约 879,594 字节。约 57%/72%/79% 是设计试算的字节降幅，不是已实施效果、token 实测或质量通过证明；RESEARCH_REPORT 尚未注入的依赖报告另计。

实施顺序限定为以下三个已有接缝，不新增通用压缩框架：

1. **审计与研究输入分开。** 原 provider audit、Gate、任务授权和 hash 完整留盘。各任务接收按其证券/数据集投影的覆盖摘要、失败原因、冲突、时间滞后、来源层级与可定位审计引用；不能把影响结论的限制仅留在磁盘或只给一个 hash。重复的逐条 ID 和机械处理记录不注入全部研究任务。
2. **目录无损去重。** 模型侧仅保留一份可查证的证据目录；可采用明确表头加行数据，仍包含准确引用、字段、证券、来源、单位及时间，缺失值语义可恢复。任务、顶层列表及格式说明不再各自重复枚举同一批 ID。完整允许集、服务端动态输出 Schema、权限和最终引用校验仍使用原契约；若提供精简格式说明，必须区别于权威 Schema，并测试所有必填项/类型/结构仍被正确说明，不能只删 enum 就认为行为等价。最终报告继续保存完整 ID；模型侧按 §7.5 使用绑定本任务的精确短引用，不截短原 ID、不自动猜测还原。此前完整 ID 直接交付的旧包保持原协议可读。
3. **先复用读取，再处理真实长文。** 现有 ID 批量查询可按已保存章节取正文；当前 MRVL Morningstar 的 14 个章节项约 22 KB，并不要求新建全文平台。以既有研究问题组织有限批次，财务事实保持期间、币种、单位、口径及来源，表格保留表头、必要脚注和引用。已保存摘录仍是摘录。当前字段查询仅对 COMMON_STOCK_RESEARCH 开放，不把它默认推广到八维；本轮复用 ID 批量查询，仅在边界按 §7.5 精确解析引用。若真实章节超过现有返回边界，才在同一读取工具内增加绑定 run/invocation/Gate/文档版本的章节或续读选择，显式已读范围、未读范围及结束标记；拼接后可与冻结章节核对。禁止任意文件路径读取、跨任务授权、跨 cutoff 内容、静默截断和把未读全文标为已读。没有超限样本时记录不新增分页的依据即可，不为可选能力扩建基础设施。

启动包保留核心问题和完整资料地图，关键财务/正文/表格通过明确目录与授权工具可达；不得由 Python 按 bullish/bearish 倾向筛选证据或生成主观摘要。计算附件、依赖报告、材料准备结果的必要语义不能随机械字段一起删掉。现有可用查询失败时保留具体缺口，不退回无依据结论。

材料准备既有 256 KiB 硬边界不变；它不自动成为正式八维或模型能力的新硬上限。正式输入在 prepare、launch 和实际 Hook 交付时使用相同序列化规则测量；依赖报告注入后再量一次。结合实际运行模型/窗口配置，分别记录规则、工具定义、任务输入、依赖及留给读取/输出的空间；不能只以 API 最大窗口代替宿主实际设置。无法精确计数时记录方法与不确定性，不凭 KB 推断必然超时，也不关闭现有传输限制。确认超过实际生效限制时在对应模型启动/交付前拒绝，不靠截断正文解决。

### 6.2 最小调试与内容效果验收

诊断复用既有运行目录、Hook/MCP 事件和消费核对输出，最多增加一份每运行的紧凑对比摘要；不新建观测服务、数据库、仪表盘或独立评分 Agent。日志只保存白名单统计、标识、hash、相对引用和首差异，不复制全部正文、凭据、账户或模型私有推理。

| 检查层 | 必须回答的问题 | 最小证据 |
|---|---|---|
| 输入前后 | 哪些字段省掉，哪些移到读取，是否丢内容？ | 同 Gate/cutoff 下每任务旧/新序列化 hash、分区字节/token、ID 总数/唯一数、留盘/摘要/按需读取清单及目录往返首差异 |
| 实际交付和读取 | 模型拿到的是哪一版，是否只把消耗转移到工具？ | 实际 Hook hash/体积、依赖注入增量、query 次数/返回量/重复 ID、章节已读与未读范围、首个失败/重试位置 |
| 运行成本 | 初始和累计消耗各是多少？ | 同一 tokenizer 名称/版本/编码和计数范围；可观测 usage 的 input/cached/output/reasoning、父子归属及不重叠汇总、开始/首工具/结束耗时 |
| 研究质量 | 精简后能否仍正确理解和引用？ | Design 八维最低内容逐项结论、报告段落/claim 到 query/calculation/原文的定位，以及数值/期间/单位/否定条件/冲突和反证的核对结果 |

Token 记录区分本地计数、近似估算与服务端实际 usage。没有模型对应编码时允许使用注明的参考编码作相对比较，不伪称精确模型计数；单纯 bytes/2–4 不作为 token 验收证明。不为计数隐式调用付费 API。首次输入、后续工具返回和多轮 usage 分列；父运行 usage 不自动视为全部子 Agent 消耗，缺失部分标 NOT_OBSERVED，缓存 token 不重复相加。不同输入/模型/推理配置的历史用量不得当严格效率 A/B。

零模型比较使用同一冻结 Gate、同任务授权、同研究问题生成旧/新表示，不启动旧版模型基准。逐项验证完整允许 ID 集与可读内容相同，目录重建及批量读取的值/时间/单位/来源等价，服务端 Schema/权限/PIT 拒绝行为不变。摘要对所有任务相关失败、滞后、冲突和正文层级限制均有对应表示；跨 run、证券越权、未来值、错文档 hash、错误续读、表格脚注与否定段落丢失须被测试识别。没有实际分页则不虚构分页测试已通过。

效率目标是同一输入下实测初始包装 token 减少，并给出各任务及合计差异；不强制达到试算的 79%，不为了百分比删除研究内容。真实总消耗/耗时没有可比基线时仅报告本轮值及不可比原因，不能宣称已降低全流程成本。初始减少但重复查询膨胀、内容遗漏或引用错误增加时，不得以体积指标关闭相应缺口。

研究质量按八维最低内容做人工/独立只读复核：财务期间与重组/集中度、研报正反观点和估值假设、同行口径、Macro/Market 传导与限制、机构两期语义、期权单位及技术 calculation 均须有可定位依据；特别抽查反证、脚注、否定条件没有被包装或分段隐藏。复用旧报告前注明输入/版本/模型可比性；可比时对新增错误、缺漏和理由变化逐项解释，而不要求结论措辞一致。若旧报告不具备同输入基准，则只能声明“输入等价检查通过、本轮质量达到最低内容”，严格 A/B 不退化标 NOT_TESTED，不伪造精度百分比，也不将其理解为股价预测准确率。发现关键质量问题仍保留未完成项；确需额外模型对照须另外批准，不能占用或增加既定预算。
