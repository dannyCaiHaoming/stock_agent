## Context

动机见 proposal.md。现有 `research_memory.py` 使用 SQLite、不可变对象和 Company 专用数据集策略；其构造函数会建目录及迁移，不能作为浏览入口。已有事实、观察、checkpoint、attempt、View、报告索引和复用事件可供查询，但没有网页目录/分页接口。

`common_stock_data.py` 将官方宏观和市场基准保存到运行目录；宏观标准化当前只保留每项最新观测，且没有 historical vintage。`multidimensional_stage.py` 生成市场状态计算与多维报告。它们没有与 Company 同等的长期持久化保障。

`research_visuals.py` 已有四组核心图、补充表、chart-data、SVG 和离线报告。`tests/test_research_memory.py`、`test_research_memory_chain.py`、`test_research_visuals.py` 具有可复用确定性样本。项目为 Python 包，当前没有独立前端工程。根 AGENTS.md、PRODUCT.md 的既有用户修改不在本 Change 修改范围。

规划复核时，当前稳定 MRVL Memory 有多个 View，但报告索引为空；公司 profile 长期对象能提供 ticker，事实表不保证存在 company_name。这意味着真实验收必须覆盖资料可读和无报告空状态，列表也必须有身份回退，不能把真实报告或公司全名作为启动前提。现有事实含可用的 10-K/10-Q 长正文和 Form 4，也含同申报的目录短句；当前页面只显示类型、日期和来源，没有展示正文或解码交易。现有报告渲染还按简化样本读取 `summary` 和数组 `sections`，与生产 `equity-research-report/1.0.0` 的 `research_summary` 和六键对象结构不一致。

## Goals / Non-Goals

**Goals:** 本机中文浏览；Company 长期资料与 Macro/Market 冻结产物统一导航；数据/报告分别选版；仅展示已有判断；后续能力通过局部适配接入；网页完全处于研究链路下游。

**Non-Goals:** 本次不通用化 Memory 写入模型，不修改研究权限和隔离，不增加持仓编辑、任务按钮、后台采集、任意时点重建或通用插件平台。持久化扩展和新研究能力有各自验收，不受网页专用呈现进度限制。

## Decisions

### 0. 本轮修复基线与最小范围

已定位真实 MRVL View 有 2068 个引用但仅解析出 1500 个，原页面没有报告其余 568 个未解析引用。样本显示事实经 freshness 标注后与原落库内容 hash 不同；不能未经逐条检查就假定全部缺失同因。旧 verification.md 仅保留为上一轮执行记录，不代表本轮正确性和可用性通过。

“导入”是读取并验证已有 Memory/冻结产物，不新增网页事实库。沿现有确定性保存接缝统一事实版本与 View 引用：保存前检查引用闭合，失败不提交成功 View/相关成功状态。freshness 等运行上下文如何保留须在实施时用真实样本和既有契约确定，禁止简单删除字段、全局换 hash 或弱化校验来强行匹配。若确需调整版本算法，必须显式兼容旧版本并验证旧报告，不引入通用迁移框架。

旧数据采用独立离线修复步骤：只读预检列出引用差异和可恢复依据；在可恢复的备份/副本上验证原对象完整性与 cutoff，再按实际授权对稳定目录执行。保留旧 View、旧报告、原 hash 与水位；修复产物记录原版到修复版的关联，只有完整校验通过才可作为默认有效版本，旧链接仍可诊断。无法验证的历史数据不补猜、不从最新事实回填。修复具备事务失败回滚及幂等检查，不由 HTTP 请求触发，不访问 Provider 或模型。本轮需求更新不等同稳定目录写入授权。

读取先检查完整 View，再分页呈现；分别计数唯一引用、已解析、缺失和校验失败，中文区分未采集、引用缺失、对象损坏、尚未适配、计算未生成与指标不适用。不完整版本显著警告，不得以图形限制卡掩盖数据错误。

### 1. 独立本机服务与可选依赖

拟新增 `product/web/` 及独立启动入口，提供服务端生成的中文 HTML、同源只读查询、少量本地交互资源。仅监听 127.0.0.1，端口可配置；校验本机 Host，禁止跨源读取，不允许任意 bind 地址。所有资源随包交付。实施选择 Python 3.11+ 标准库 `http.server`/`sqlite3`，不新增第三方 web 依赖；该模块仍只由独立入口导入，不进入 Agent 启动导入链。

不建设 SPA/Node 工程、远端数据库、WebSocket 和用户系统：首版交互以搜索、页签、选版、表格和 SVG 为主。已有离线 HTML 继续独立可搬移；网页的交互不修改离线报告的无脚本契约。

### 2. 两类读取适配器，一个轻量页面模型

Memory adapter 以 SQLite URI `mode=ro` 和 query-only 连接读取受支持 schema，短事务取得一页所需索引/绑定，关闭后才做对象校验及呈现；不调用写入型初始化、不设置 journal_mode、不使用 immutable 模式忽略活动 WAL。读超时有界，繁忙提示重试，不能持锁等待浏览器。WAL/SHM 的 SQLite 协调行为与业务写入分开验收；权限不足时报告，禁止提权或复制主文件绕过 WAL。

Frozen artifact adapter 接受可重复的显式 `run-dir`，并可选接受显式 `run-root`。前者只检查指定运行/资料目录，后者只发现直属且包含已知 manifest 的运行子目录；不递归扫描整个磁盘、用户目录或临时目录。支持单独 source-package 和完整运行目录；按 schema、hash、对象身份和允许附件绑定校验，不凭文件名认定真实报告。目录或对象缺失时保持状态可见。

页面模型保留对象 ID、能力、产物类型/版本、稳定报告或 View ID、时间、来源、覆盖、内容引用与展示区块。它仅供浏览，不成为新 Agent 输出契约或第二事实库。同一稳定身份及 hash 去重；稳定身份相同但 hash 不同则形成可见冲突，不按配置顺序选择。列表按 cutoff/稳定 ID 排序并分页，初始每页 50、上限 200；不在每次列表请求加载全部报告正文和图表。无持久化索引服务；必要目录索引仅驻留内存，可由“重新扫描已配置目录”更新，该操作不访问网络。

### 3. 首版页面信息架构

| 页面 | 默认可见内容 | 详细内容与限制 |
| --- | --- | --- |
| 总览 | 三栏目入口、已保存公司数、最近资料与报告、缺口提示 | 不提供全库投资评分或当前持仓推断 |
| Macro | CPI 指数、失业率、10Y 最新已保存观测 | 观察期/获取时间/来源；已有研究；单点不画趋势，多次快照按实际观测与版本保留，不能冒充历史 vintage |
| Market | 已有基准日线、已有 20/60/252 日统计 | 价格与收益口径、实际窗口、回撤与量价；计算产物不存在时显示未生成，不追加算法 |
| Company 列表 | ticker/security_id、可得的公司名称、最新资料时间、最近财报期、报告及缺口状态 | 搜索、分页；所有公司均为已保存对象，名称不作为必填身份 |
| Company 详情 | 概览、财务、行情与估值、研究记录、数据来源 | 披露与事件作为财务或研究时间线；指引、债务、治理等按已有附件展示；缺口保留 |
| 来源与数据状态 | 更新时间与可读状态 | 展开 source_id/三时间、checkpoint、attempt、pending、版本与 hash |

不将四类状态压缩成一个绿色“成功”：数据覆盖、来源检查、执行结果、研究充分性单独保留。列表可以用简短中文提示，详情能定位原状态和原因。技术字段默认折叠。

页面顶部固定并列“资料截止 / 最近检查 / 报告研究截止”，缺失项使用“未保存”或“尚无报告”，不以一个“最新”标签覆盖三种时间。公司列表默认按最近资料变化排序，并提供有新资料但无新报告、数据有缺口、来源失败和尚无报告四个筛选。版本比较默认只展示变化项，未变化事实按需展开；业务分组优先于原始 Evidence 列表。

Company 首屏显示身份、所选版本日期和紧凑覆盖提示，随后显示营收、净利润、稀释 EPS、经营现金流四项核心卡片；资本开支、现金、债务放在财务区。各卡按明确的指标/期间类型选择该 View 内最新可比值，标注财年、季度或累计期间，缺项单独说明。中文格式显示金额的万/亿、每股值和百分比，原始精度在详情保留；来源值与派生值分开。不新增利润率、TTM 或增长率算法，已有合格派生值可以展示。

财务区按指标展示期间表和独立趋势；行情区默认图形，逐日明细由“查看数据”进入并分页；披露按时间线列标题、日期、摘录及原文入口；报告以可阅读章节呈现而非原始 JSON。来源详情从具体指标/图表点进入，能定位事实版本或附件行及来源三时间。技术诊断仅在来源高级详情内展开，默认不显示大段内部状态。

披露与研究使用两层模型，避免把确定性整理伪装成投资解读：

1. **事实事件层**：从所选 View 的已保存披露事实生成时间线。按 source/form/period/semantic field 聚合，优先有实质内容的正文，目录短句和重复标题折叠但保留来源详情。Form 4 仅解码实际字段（交易性质、数量、价格、交易后持仓）；不以规则推断利好、利空或重要性。
2. **已保存研究层**：只展示已经持久化且绑定校验通过的模型报告。Company 主报告严格按 `equity-research-report/1.0.0` 适配状态、`research_summary`、六个 sections、claims/evidence、assumptions、催化剂/反证、失效与再评估条件、监控项、缺口、置信度及其依据。多维 `FUNDAMENTAL_EVENT`、`RESEARCH_REPORT`、`OWNERSHIP_DISCLOSURE`、`INDUSTRY_COMPARISON` 报告作为补充卡片，不与主报告合并成新的判断。

页面没有报告时说明“未保存/未生成”，而不是“没有事件”或“没有观点”。浏览请求不生成摘要、不运行 Company Agent 或多维 Agent，也不把确定性模板文字称为 Agent 解读。

### 4. 已保存版本选择与报告绑定

Company 默认选最新已保存 View；无 View 时可提供明确标注的事实目录，不将任意聚合称为已冻结 View。Macro/Market 默认各自最新快照，页面没有跨对象共同 cutoff 时不捏造全局统一截止时间。历史选择器枚举真实版本，日期过滤只缩小候选或图表窗口。

详情中的最新事实与最近报告分开标注；进入报告后固定其原始包、cutoff 和附件，不拼接最新资料。浏览不得调用 record_reuse，读取不是一次研究复用检查。私有 request 不进入响应模型。

最近检查时间优先来自绑定对象的最新 attempt 或 reuse event；没有这些记录时才显示“没有已保存检查记录”，不能使用 reports.stored_at 猜测后续检查。公司身份优先读取受校验 profile/snapshot 中的 ticker，再使用 `security_id`；公司名称只读取合格公开资料，不存在时不伪造。该优先级只服务展示，不建立新的身份主数据。

View 比较只比较同一 security_id 的 selected_fact_versions，利用 fact_versions.logical_key 对齐；不同语义键不硬配对，分别显示新增、修订、仅一侧存在、未变化及不可比较原因。默认按财务事实、估值输入、新增披露、数据缺口和报告版本分组，只显示变化项，原始 Evidence/hash 在展开区。报告并排保持原文，不做模型总结或关键词规则 Thesis 评分。

### 5. 图表复用与来源约束

优先消费已验证 visual_bundle 和 chart-data；复用现有纯计算/纯渲染接缝，必要时小范围抽出纯校验函数，避免调用 persist_visual_report 写入浏览源目录。价格/成交量、相对表现/回撤、财务趋势、历史估值四组路径分别输出图、事实表或具体限制卡；MRVL 历史 PE 不可用是合法限制结果。已有市场日线可直接确定性绘图，收益、波动等数值来自已有计算，不把补齐估值算法作为网页任务。

呈现保持负值、缺口和主体/会计断点。来源指标、派生指标和指标不适用独立标注；financial period、unit、currency、price basis 保留。已保存的 SEC 摘录显示摘录及链接；没有完整正文对象时不能声称全文可读。

无专用附件时，从完整 View 中的已知语义字段绘图，不依赖模型报告。按指标、period_start/end、期间类型、单位、币种和会计口径分组；同 period_end 的季度与累计值不可互换，修订不能按数组顺序任取。多点同口径才画趋势，单点保留卡片/表格。金额、EPS 分图；价格和成交量分区且各自具备数据；原价与复权价不混连。图表 AVAILABLE 必须有有效数据并实际渲染，PE 字段存在但 data 为空不能通过。附件严格验证证券、run、cutoff、版本、hash；旧版本页面不能借用同截止点其他运行的图形。

### 6. 扩展规则与兼容

使用代码内小型 registry 映射 artifact kind/schema version 到 adapter，再按 capability/object scope 映射到栏目。复用指标卡、表格、时间线、图表、报告文本这些有限组件；不建设任意 JSON 自动生成页面、插件安装或动态执行机制。

同类型新股票/记录自动发现；新指标调整字段映射；新能力复用报告格式时增加映射；全新数据结构增加专用 adapter/renderer。未知版本只显示经安全提取的类型/版本及不支持提示，既不猜测兼容，也不阻塞已有类型。一个共享 MACRO_MARKET 报告可以在两栏链接到同一 ID。后续 Skeptic 的接入只影响自身呈现适配，不改变其独立首轮权限；网页支持不得加入任何 Agent 的完成门禁。

### 7. 本机隐私与文件呈现

网页请求使用服务内部对象 ID，不接受任意绝对路径。所有文件引用进行根目录约束、符号链接和 hash 检查；对外屏蔽实际路径、private request、持仓/账户字段和来源凭据。报告正文按已有研究内容显示，不能保证正文绝不提及用户研究问题，因而不提供公共分享入口。

Markdown 禁止原始可执行 HTML，文本转义；已有 HTML/SVG 仅经允许的验证/安全呈现路径打开，浏览器策略禁止执行来源脚本和自动外联。来源链接仅显式点击打开；不提供整包下载或任意静态文件服务器。首版不增加鉴权系统，但 loopback、Host 与同源约束必须验证。

### 8. 验收证据与完成边界

| 验收层 | 样本与证据 | 完成标准 |
| --- | --- | --- |
| 真实阅读 | 已有 MRVL Memory，按授权读取，不采集；真实报告仅在索引存在时使用 | 搜索→详情→View/实际附件→来源可追溯；报告为空时正确显示，报告页面由确定性样本覆盖 |
| 功能 | 标记为测试的两份 View/报告、宏观和市场完整/受限产物 | 时间、差异、单位、状态、未知版本、缺失/损坏隔离均正确 |
| 只读并发 | 临时库＋独立写入器＋SQL/调用边界记录 | 无网页 DML/迁移/Provider/模型调用，写入预期正常提交，读取无部分事务或长期锁 |
| 视觉 | 桌面约 1440px、窄屏 390px 实际浏览器截图 | 中文、图例、负值、缺口、长表、导航可读；表格局部滚动，无页面整体溢出 |
| 兼容与扩展 | 旧无附件报告、额外字段/新证券、未知格式 | 已有页面正常；新已知记录自动出现，新增能力只需局部映射示例 |

报告样本必须通过生产 schema 校验，并检查状态、`research_summary`、六个命名章节、claims/证据、assumptions、反证或失效条件、监控、缺口与置信度依据；不得继续用只有顶层 `summary` 和数组 `sections` 的简化假格式覆盖报告验收。事件样本同时包含同申报的目录短句与正文、Form 4 结构化交易和无模型报告状态，验证事实层、研究层及空状态不会互相冒充。

真实 MRVL Memory 不可读时阻断对应资料验收，不用其他股票代替。真实 MRVL 报告、Macro/Market 或第二份模型报告缺失不阻断：其页面使用明确测试样本验收，实际页面显示空状态。不得为本 Change 自动调用模型、Provider、Runtime Eval 或 Promotion。独立复核基于规格、差异和这些证据，人工完成批准后才归档。

本轮另设硬门禁：目标 MRVL 有效 View 所有引用解析且 hash 校验通过；已有营收、净利润、EPS、经营现金流逐项对账到页面。568 为已发现缺陷的诊断基线，不是未来固定条数；不得通过删减引用达标。样本覆盖 freshness 前后、悬空引用、错误 hash、重复修复、修复失败回滚、季度/累计同日、混合单位、空 PE、同 cutoff 不同 run、历史切换与逐项来源。桌面/窄屏实际完成查营收及期间、看趋势、看证据、切历史四步，默认不展开价格明细及技术状态。记录引用计数、业务对账与截图证据；只读证明使用 SQL/调用边界和逻辑状态对账，不能仅以主数据库文件 hash 代替含 WAL 的一致性证明。

## Risks / Trade-offs

- 冻结目录被清理 → 明确它是引用来源；记录不可用，不在网页需求内偷偷引入长期归档或同步。
- 浏览版本领先/落后于 Memory → 只接受已声明支持的 schema；生产迁移仍由现有维护入口承担。
- 大报告加载或列表扫描变慢 → 分页、按需加载，缩小显式来源目录；不先建设缓存数据库。
- 报告 hash 合格但文本含 HTML → 校验与安全呈现分别执行，不能用完整性校验替代转义。
- 同时运行造成库文件 hash 改变 → 分别测试无写入器时逻辑不变和有写入器时预期提交；不以整体文件 hash 代替只读证明。
- 缺图被误认为功能失败 → 分开标记格式不支持、未生成、数据不足、指标不适用和损坏，不接受所有核心展示均为空的假验收。

## Migration Plan

新增可选浏览模块与本机入口，配置 Memory 及冻结目录即可启动，浏览不执行数据库迁移或历史修复。已有损坏引用按第 0 节独立维护流程处理，不改写历史报告或 Agent 配置，不预设需要 schema 迁移。停止网页即可退出使用，长期资料和原调度保持独立。使用说明记录启动/停止、本地读取刷新、预检/修复边界、支持版本、数据缺口与私人产物边界；不写入用户实际私人路径到仓库样例。
