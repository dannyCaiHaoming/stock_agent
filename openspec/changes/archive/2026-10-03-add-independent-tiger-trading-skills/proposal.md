## Why

用户希望从 Mac 上已登录的老虎证券客户端整理自己的真实交易，并在逐个标的的 K 线上查看买卖，再结合交易当时可知的市场与事件反思交易过程。现有未收尾的 Tiger Change 使用 TBHK OpenAPI 与确定性统计，尚不覆盖客户端读取、K 线成交标记或 LLM 交易反思；本次以两个可独立调用的 Skill 交付，改善个人交易记录的可读取性与复盘质量。

## What Changes

- 新增 `tiger-trade-journal` Skill：每次新采集取得用户指定的开始日期和截止日期，以自定义区间为主要入口，保留一周、一个月、半年、一年作为快捷填入日期的选项；新请求不再提供“开户至今”。依据用户 2026-10-02 明确的方法选择，优先通过 computer-use 操作已登录 Mac 客户端的历史页面与正式导出，再由本地工具解析、验证及保存；已实现的受限 native 采集器保留为可选入口，不作为每次导航的前置开发任务。未知界面、登录失效或覆盖不足必须明确停止或报告缺口，不切换到 Cookie、客户端数据库或 OpenAPI 认证。
- 保存股票、ETF 与上市期权的逐笔成交、证券身份、费用、来源、业务时间、采集时间及修订。按账户、标的与完整期权合约组织历史；订单、成交、到期、行权、指派和资金活动分别呈现，不能把委托等同于实际买卖。
- 用户已明确选择本地 `product/` 专用目录。新增 `product/.private/trading-journal/` 私人存储区，保存原始允许材料、SQLite 账本、冻结行情、图表和复盘报告，设置本机权限并验证 Git 与插件发布排除；不放宽既有 Tiger OpenAPI 账本的仓库外路径限制。
- 生成可本机打开、筛选标的与周期的 K 线交易图，显示逐笔买卖时间、价格、数量和费用。股票/ETF 使用同一价格口径；期权先在标的 K 线上按时间标记完整合约与交易动作，权利金保持独立数值；有可靠期权历史行情时再展示独立期权图。缺失行情、时间精度和多币种限制可见。
- 新增 `trading-reflection` Skill：消费冻结账本、图表、确定性统计和 point-in-time 宏观/指数/公司事件材料，由 LLM 分析入场、加减仓、退出、持有与风险管理，区分当时决策质量与事后结果，给出有证据的反例、替代解释及可执行的练习/复盘计划；不把盈亏直接变成能力评分，不从交易记录猜测用户心理或原始意图。
- 按用户确认的选择式展示要求，提供可重复生成的本地合并查看入口：初始直接显示已保存复盘要点及改进建议，选择标的后显示一个图表工作区及相关总结；覆盖、进度、目录及来源退到按需展开。仅在存在对应冻结日 K 的成交日蜡烛上显示 B/S/T，悬停蜡烛在图内显示当天全部操作；同日多笔不增加图上箭头、数量框或引线，明细分页不截断可读取记录；自选区间可连续跨年，年份只作为可选快捷筛选。图表支持时间轴缩放、拖动平移和恢复整个区间，成交、焦点及事件随同一坐标变换保持对齐。全部复盘继续可发现和切换，筛选不删改报告或遗漏记录。
- 复盘新增版本化的图表讲解：LLM 为每个案例提交焦点成交、图窗、初学读图、改错练习、深入反证及相关事件引用；工具从可信资料派生时间锚点与逐笔 PIT 层，不生成判断或补造指数、事件、期权报价。旧报告只读兼容。
- 保留固定版本的短时只读查看入口，并增加显式启动、固定本机端口的持续交易工作台，读取最新已验证时间线和各自绑定原输入的复盘版本。提供刷新已保存资料、显式更新公开K线及用户选择官方CSV的本地导入；窄范围写动作需同源会话与明确点击，不提供任意文件服务、网页账户调用或第二套模型编排。工具访问准入独立于用户授权和功能实现；拒绝访问后不得换协议或通道绕过，不以合成验证冒称真实浏览器验收。
- 对这两个独立 Skill 的全部阅读界面统一优化：默认区、展开区、目录、提示、来源、成交与事件详情、打印、新生成中文 Markdown 报告及 Skill 交付文字均使用易读的证券、时间、动作和资料标题，不展示 hash、内部 ID、私人路径、原始 JSON 或协议代码；技术身份及验证字段仍完整保存在后台，不改写旧报告判断。
- 两个 Skill 直接在 Codex 中使用，不要求有效组合 Handoff，不接入 Council、CIO、Research Memory、Risk、现有 `/trades` 或产品 Runtime 编排。数值、去重、行情对齐与持久化由确定性辅助工具处理；私人历史不会自动成为公司研究 Evidence。

## Capabilities

### New Capabilities

- `tiger-desktop-trade-journal`：Mac 已登录客户端的受限只读采集、窗口问答、交易规范化、私有持久化、覆盖证明与逐标的 K 线成交展示。
- `historical-trading-reflection`：基于个人真实交易与交易当时可知证据的 LLM 反思、确定性统计消费、反例与改进跟踪。

### Modified Capabilities

无。本次新增独立入口，不改变当前 Intake、Council、Research Memory、浏览器或已规划 TBHK OpenAPI 的行为契约。

## Impact

- 预计新增 `product/skills/tiger-trade-journal/`、`product/skills/trading-reflection/` 与仅服务这两个 Skill 的本地辅助模块，按实际需要提供 scripts/references；登记 Skill 版本，不修改候选生产版本指针或新增研究 Agent。
- 修改 `.gitignore`、现有 `product/` 复制边界及插件来源/发布副本检查，支持用户授权的仓库内私人目录；真实账户记录、原始导出、图表、报告、缓存与数据库均不进入 Git、模型工作区、插件副本或云端 Space。这些共享入口只增加私人目录排除，不接入新的 Runtime 研究阶段；插件副本使用锁定的已审阅基线及本 Change 范围，不夹带其他工作树修改。
