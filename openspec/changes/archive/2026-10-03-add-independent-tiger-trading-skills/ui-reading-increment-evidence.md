# 自选日期、图表操作与统一阅读增量证据

## 可观察结果

- 新采集一次询问开始和截止日期，保留一周、一个月、半年、一年快捷选择；不再推荐开户至今。日期包含首尾，未来截止冻结到请求时刻，缺边界和逆序拒绝；所有导入模式入账前过滤到精确区间。图表沿用该次导入返回的冻结版本，防止选择期间被全账本替代。
- 页面日期可以连续跨年。年份只作快捷填写，可恢复原自选区间。SVG 支持指针中心滚轮缩放、水平拖动、放大/缩小、早/晚移动和恢复整个区间，价格轴按可见价格调整；股票价位、期权时间栏、焦点及事件使用相同时间变换和裁剪。
- 全部阅读出口使用业务标签。默认、展开详情、来源、事件、计算、目录、提示、打印及新的中文阅读 Markdown 均隐藏技术身份，保留金融数值、公开网址、当时/事后/不确定层和真实限制。原研究字段及隐藏定位引用保持不变。
- 报告成交范围、请求区间、来源返回范围分别显示；日期视窗不重新分析或重算原统计。真实账本没有顶层实际起止字段的形状已有反例，来源观察和覆盖缺口通过白名单保留，未带出账户、原始回执或私人路径。
