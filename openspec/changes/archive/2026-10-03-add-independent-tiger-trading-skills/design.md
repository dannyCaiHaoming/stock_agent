## Goals / Non-Goals

**Goals:**

- 两个独立 Skill 可在 Codex 当前会话使用，辅助工具只执行采集、计算、验证、绘图与保存，不充当研究 Agent。
- 相同记录重复取得不增加经济活动，修订不重写旧报告，用户能在 K 线标记与逐笔事实之间往返核验。
- 把当时可知背景、事后结果与主观解释分层交给 LLM，减少“赚钱就是做对、亏钱就是做错”的复盘偏差。
- 先完成私人目录实际隔离，再允许第一笔真实账户材料落盘。

**Non-Goals:**

- 不接入 Intake、Council、CIO、Risk、Research Memory 或现有 `/trades`；共享源码改动仅服务私人目录复制排除和 Skill 发现/版本一致性。
- 不控制交易、账户设置或权限配置，不读取 Keychain、Cookie、Token、老虎内部数据库或非公开接口，不假设客户端所有版本都能自动导航。
- 不建立开机自启、定时账户采集、模型调用编排器、税务系统或策略回测。第12节允许用户显式启动、持续运行直到停止的回环交易工作台，复用现有Python/HTML/SVG；固定版本短时查看器继续兼容，不修改生产候选指针。

## Decisions

### 1. 两个 Skill 共用一套小型确定性支撑模块

入口采用 `product/skills/tiger-trade-journal/SKILL.md` 与 `product/skills/trading-reflection/SKILL.md`。前者说明周期问答、采集/查看模式与来源限制；后者说明研究方法、证据选择、反例与改进输出。长篇字段映射和来源说明按需放在各自 `references/`，不用 Skill 指令重复粘贴全部技术契约。

必要支撑模块放在 `product/trading_journal/`，提供受限采集、解析、账本、行情冻结、确定性统计和 HTML/SVG 输出；Skill 内 scripts 是薄入口。模块不能导入 Council/Runtime 调度，也不引入 Tiger SDK。现有 Tiger 时间处理、内容 hash 与 FIFO 逻辑只在接口确为纯函数且适用时复用；不为复用重构整个旧 Change。

Skill 的 `metadata.version` 与 manifest 登记一致，不新增 Agent、模型路由或候选晋升。直接加入已有 Skill 发现目录，比新增插件或第二套编排更小；此处“独立”指运行不依赖组合系统，而不是另建系统。入口明确这是个人历史记录/反思模式，不继承 Council 的 `NO_TRADE` 输出、CIO 身份或 Runtime 权限；通过两份 Skill 内的窄范围调用政策说明，持久化仍由确定性本地层执行，不修改既有产品运行政策。

### 2. 采集先问范围，读取已有记录无需再问

2026-10-03 起，新采集以用户指定开始日期和截止日期为主要入口，一周、一个月、半年、一年保留为快捷填写，不再提供“开户至今”。同一请求已指定区间直接复用；缺少边界时一次问清。用户时区默认 `Asia/Shanghai`；日期区间包含首尾日期，完整 ISO 时刻保留精度，未来截止截至本次冻结的请求时刻；逆序和格式错误在采集前拒绝。一周回推七天，月/半年/年按日历回推并处理月末。说明实际起止时刻后按客户端允许跨度分段，日期查询多取的记录仍按实际成交时间过滤，边界规则写入 manifest。

不再为新请求追查或推测开户日。旧 lifetime 请求仅兼容读取及内部参数解释，原始覆盖事实不改写，不重新加入用户选项。自选区间仍分别记录请求与实际范围，来源不能证明完整时保留缺口。读取已有图表和复盘默认读取已保存版本，不打开老虎；页面起止日期只筛选已保存数据，不能被解释为重新采集。一次请求内已经选定范围、账户和本地目录后不逐页请求确认。

### 3. GUI 优先 computer-use，持久化仍由确定性工具负责

用户于 2026-10-02 明确要求改用 computer-use，并已通过该工具实际进入“账户 → 交易历史 → 交易记录”。Skill 优先使用当前 computer-use 的 AX 与截图完成导航，按当前界面识别标签并在动作后核验新页面，不写死坐标、不临时开发新点击桥。该版本的多个页签可能在 AX 中合并成一个文本节点，必要时从当前截图定位单个页签。未选期间可定位页面和查看日期选项，但不选择范围、主动逐行提取/分析、导出或保存交易；必要页面观察附带的交易行只用于识别页面，不复述或加工。

computer-use 的交互范围只有已登录目标应用的账户/历史页导航、用户所选日期、市场/品种筛选、必要只读详情和官方导出/本地保存。这个通用工具的安全性不能冒称由本项目 native 硬接口保证；它保留用户明确要求的交互观察，订单、交易解锁、行权、资金和账户写入始终禁止。原始截图/AX 可能附带身份信息，不额外另存、转写到普通文档、报告或发布物；优先用不直接回显的观察和必要的脱敏摘要，必须识别页面时才取得截图，不声称工具会话未留观察。正式文件仅保存到已验证的私人 sources，完整身份不进入规范化账本或复盘材料。

computer-use 官方导出以 `COMPUTER_USE_EXPORT` 独立记录，不标成用户手工导入或 native `VERIFIED_DESKTOP`。导入前校验脱敏观察回执与真实文件 hash、期间、来源时区、视图和有限动作类别，原回执留私人 sources，账本只引用其安全身份/hash。该校验仅证明材料与观察声明绑定，不能机械证明 CUA 动作发生；实际执行由工具结果与实机复核证明，也不能据此提升覆盖状态或把下单/状态更新时间当成交时间。

2026-10-02 实机取得的正式逐笔账单来自“账户 → 资产分析 → 账户信息 → 账单报表”跳转的官方已登录网页，选择 CSV 与“显示逐笔成交记录”。此格式按区段解释：交易明细的 `DATA` 父行是汇总，代码为空的子行是实际逐笔；`TOTAL` 不进入账本。只消费股票（名称明确 ETF 时保留 ETF）与上市期权，基金和外汇区段不进入本 Skill 的证券交易账本。父子数量、成交额和按位置读取的各费用组件勾稽后只输出子行；重复标题“交易费用”是两个组件位置，不据此猜总费用。期权乘数仅从金融产品信息按完整合约匹配，调整状态未知继续保留。

该账单的 `成交时间` 自带 `US/Eastern` 或 `GMT+8` 后缀，以 `account_statement/PER_ROW` 回执声明逐行明确时区；此标识仅开放给严格匹配已知完整标头的账单，不是通用 CSV 的缺省时区。子行时间后缀缺失、父子失配或无逐笔明细均拒绝。原始其他区段中的姓名、账户、地址不进入规范化字段。浏览器下载等待超时须核对实际下载记录与文件，不盲目重复；默认下载路径无法预设时立即将实际文件移入私人 sources、使用中性名称并设置 `0600`。报告实际返回范围与请求范围不同仍记录覆盖缺口，不把报告起点当作开户日。

以下固定 native 接口继续作为已实现的可选方法，其页面配置未核验时不自动选用或为普通采集反复编译适配。

native 方法对安装的 Tiger Trade 验证应用 bundle、版本、界面语言、账户范围和正式历史/导出路径。Mac 辅助功能提供可识别控件时，使用已实现的本地独立进程受限动作集合：`open_app`、`read_history_view`、`set_history_window`、`read_next_page`、`export_history`。接口实现不等于当前版本的历史页面配置和真实采集已获实机核验。

每个动作绑定确认过的应用、窗口、只读页面与控件身份；不接收任意坐标、键盘序列、脚本或可执行 selector。执行前再次核验页面及动作允许条件，交易面板、行权按钮、资金操作和未知对话框一律拒绝。固定配置按实际客户端验证形成，不从官方文字猜测按钮坐标；来源材料不参与动作配置。

用户于 2026-10-02 明确要求由助手操作客户端寻找对应页面。为此，增加独立的 `navigate_history` 导航动作：用户尚未选期间时也可打开已核验的账户/历史入口，但该动作只返回本地过滤后的控件摘要，不读取成交行、设置日期、查询或导出。财务动作继续要求已选期间及原有隔离、页面与刷新证明。不得为导航编造采集期间。

实机 9.27.2 的侧栏标签由 `AXStaticText.AXValue` 提供，处于 `AXGroup -> AXList -> AXList -> AXScrollArea -> AXWindow`；原来仅检查 title/description 会漏掉它们。在读取 Value 前，必须先按完整祖先链、窗口归属、唯一性和已核验固定侧栏结构正向确认导航叶节点：各项为 Image+StaticText 的 Group，内外 List 及 ScrollArea 的结构与实机相符，边界处于主窗口的窄侧栏。只在该范围内做固定短标签完全匹配；其他静态节点的 Value 不读取。未知导航值立即丢弃，不输出其内容或 hash。数据表内的同名列标题永远不能获得导航资格，祖先链循环、截断或未知身份立即拒绝。

导航动作只能使用当前脱敏摘要中唯一的允许类别及控件身份；执行前重新核验安装版本、窗口、完整祖先链和控件状态。优先使用系统暴露的按钮/选择动作；若实机自绘侧栏没有系统动作，可在核验过的固定侧栏结构内，用当前 AX 控件边界定位，二次命中检查、前台应用及窗口归属检查后执行一次内部语义点击。接口不接受坐标或鼠标/键盘命令，不能将该适配用于交易控件、表格、输入框、未知弹层或其他应用。无法证明身份、几何位置或命中关系时停止该动作。每步后重新取得脱敏布局，历史导航与真实采集的验收分别记录。

实机侧栏七个无 AXPress 的 AXGroup 均报告 enabled=false，内部 Label 和 Image 均明确 enabled=true。这个版本的账户点击将 Group 仅用于固定结构/边界/命中；交互启用检查要求实际语义 Label 与 Image 都为 true，未知/false 拒绝，最终发出事件前重读并确认 Group 仍无 AXPress。真正 Button/AXPress 的 enabled 检查保持不变；该取舍不得泛化到其他界面或声称 SDK 规定 Group 状态普遍无意义。已前台的同 PID 不重复激活；需要激活时有界推进主 RunLoop 的实际运行模式并重新取得全部证明。导航失败返回固定阶段与是否请求激活、是否可能已发出导航动作的最小审计，不把动作后失败当作从未执行。

实机进一步确认应用可以处于前台而唯一业务窗口仍最小化：AXMinimized=true、CG 全窗口表有同 PID 的窗口但 onscreen=false。固定 `open_app` 在核验同一安装、版本、PID 及唯一窗口的完整归属后，可恢复这个已核验窗口并把它带到前台；只允许其窗口层的 Minimized 属性，不操作账户内容，也不暴露通用窗口命令。属性不明确、不可写、归属或窗口数量变化时拒绝。恢复后必须重新确认非最小化、同 PID 的精确可见窗口边界及前台状态；启动或激活调用成功不能替代窗口可见证明，恢复后的失败也不能当作没有发生窗口动作。原导航命中门禁保持不变。

native 方法首次状态核验仍由受限本地 AX/控件提取器先过滤与脱敏，再返回允许的应用版本、控件身份和字段摘要。按用户要求使用 computer-use 时，采用上述显式交互路径，不伪造 native profile、查询证明或自动验收。两种方法均在无法确认下一步只读控件时停止相关动作；确需用户手工取得的文件仍标为用户辅助。正式材料同样由本地采集/解析进程先脱敏后交付。

优先获取正式 CSV；若正式路径跳转网页，只允许实机核验的官方账单域和已登录页面，不提取认证材料。网页未登录时用户自行完成登录。只有 PDF 或界面列表时，采用相应固定解析/分页适配；OCR 只能生成待核验事实，精确金额、时间、合约等关键字段未经勾稽不能自动准入。

动作与查询有有限的时间/页数预算；重复页面、异常跳转、未知格式或范围耗尽保存 gap 和进度，禁止无界点击。成交记录来自实际成交详情，不仅从 `FILLED` 订单列表筛选。

### 4. 用户指定的本地私人目录需要三处实证隔离

路径绑定用户已选择的绝对 `repository_root=/Users/caihaoming/Documents/stock_agent`，私人 root 为该根下的 `product/.private/trading-journal/`，目录 `0700`、文件 `0600`。这是当前用户的绑定值，安装后的通用 Skill 由明确项目配置/参数取得并验证根目录，不能从 `__file__`、缓存 Skill 位置或任意 cwd 推断；根不匹配时停止，不扫描其他账本。代码缓存仅放源码，任何插件更新不得在缓存旁创建数据。拒绝符号链接和越界路径。账户使用随机本地引用，不以完整账户号 hash 替代隐私隔离。

在首次真实保存前完成：

1. Git：加入窄范围忽略，验证新文件被忽略且该路径没有已跟踪文件。
2. 模型与测试复制：给现有整个 `product/` 的复制入口增加明确 `.private` 排除；普通研究、Replay/包物化和相关测试使用哨兵证明内容不被复制。只改变文件隔离，不启动产品或改变研究语义。
3. 插件/发布：当前没有可引用的 `.pluginignore` 支持，不编造配置。用小型洁净副本工具从已审阅且与当前实际使用产品等价的不可变来源（明确 commit 或安装快照 hash）开始，只叠加本 Change 已审阅文件/hunk，硬排除 `.private`、符号链接与越界文件。不能递归读取 dirty 工作树的所有 tracked 文件，tracked 不等于审阅通过。核验当前插件加载源和可恢复来源后，才将本地 marketplace 安装/更新源切换到洁净副本；无法证明其他现用能力等价时阻断切换，不能代为收尾其他 Change。首次私人写入前必须确认实际插件缓存/副本只来自洁净来源。若不能证明当前 App 的安装/更新复制边界，就保持真实写入阻断。构建 Python 分发物时同样验证私人哨兵未进入实际产物。

洁净副本位于既有私有运行临时区域或仓库外临时目录，只是文件物化，不增加版本注册服务或发布系统。发布动作仍需要原开发流程授权。

原始账单仅在私人 `sources/` 留存，采集器与解析器允许读取；对外只提供脱敏交易区段、源 hash 和随机来源引用。即使原始导出含姓名/账户号，它们也不进入账本规范化字段、LLM、图表或日志。认证材料从不读取或保存。个人复盘显式使用最小脱敏内容，普通公司研究不读取这个目录。

### 5. 一个 SQLite 账本加普通产物目录

目录使用 `sources/`、`market/`、`artifacts/` 与单一 `journal.sqlite`，不建立对象存储、事件总线或复杂 checkpoint 服务。数据库核心职责为导入批次/覆盖、事实修订、行情/统计包索引和复盘版本；内部表不各自升级成公共 Schema。

边界包使用 `TradeJournalSnapshot` 与 `TradingReflectionReport`，图表数据内嵌前者。承载事实的记录包含 `source_id/as_of/retrieved_at`，另外保存 `occurred_at`、来源时区、UTC、时间精度、来源位置、身份与内容 hash。来源 ID 优先券商成交 ID；无成交 ID 时保留文件、行号/页号、窗口与重叠核验信息。同秒同价同量不能自动合并；无法识别跨文件重复时保留候选并排除有歧义的统计。

批次校验后短事务提交；变更追加 revision，图表与报告冻结所消费 revision/hash。解析失败保留批次诊断，不覆盖成功账本；费用修订触发新统计版本，不重写旧分析。覆盖用 `PARTIAL`、`SOURCE_COMPLETE_FOR_WINDOW`、`LIFETIME_RECONCILED` 区分：最后一项仅在可靠开户起点、全部类别/月份、分段终止与账单勾稽都有证据时产生，否则保留未知。默认界面显示中文说明而不是只显示状态码。

### 6. 股票 ETF 与期权按事实身份组织

股票与 ETF 用市场、证券稳定身份、交易币种和历史代码组织，不能仅按 ticker。期权除上述字段外保留 underlying、到期日、strike、Call/Put、合约代码、乘数及调整状态。所有来源可见的股票、ETF、上市期权都保留，不沿用旧 API 分析的 US/USD 静默过滤；行情未支持市场和未知币种单独披露。

买卖与开平仓分开；来源没有 position effect 时不猜 BTO/STC/STO/BTC。行权、指派、到期、转仓和公司行动是独立事件，建立股票/期权因果关联必须有来源依据；它们不画成普通买卖。多腿策略同样需要明确关联证据。非标准乘数不默认 100。

数值采用 Decimal 与版本化公式。第一版仅计算可闭合交易片段的数量、净盈亏、费用、持有期及相应按证券/期间汇总；FIFO 是复盘配对约定，不是税务口径。期初仓位、费用或生命周期不完整时指标为不可计算；卖空、穿越零仓位与窗口前后成交必须明确处理。按原币种分组，不直接合计；不为本次功能新增账户净值收益引擎。

### 7. 选择式图表、只读查看入口与价格口径

保留独立离线 HTML，并为明确选择提供 SVG K 线与少量原生 JavaScript。初始直接显示已保存复盘要点和改进建议，选择标的后仅显示一个图表工作区及相关总结。目录、覆盖、进度、统计与来源默认折叠，不再占用主内容区。默认隐藏长成交表，日期买卖标记使用整个已选区间，逐笔详情分页只限制明细。没有远程前端依赖、遥测、同步按钮或老虎图表画线操作；只读取冻结数据。

合并复盘由 `review-reflection --report-id <已保存版本>` 核验报告、冻结包与本地账本快照一致性后生成内容 hash 绑定的离线页。所有发现保留可搜索/分页的阅读入口，默认展示原文要点及已有改进项，完整引用与三层深入讲解按需展开；显式选中案例才定位其焦点和窗口，跨标的反例独立切换，不能混放价格轴。点击成交重建标的/合约及目标图窗并定位明细，年份是可选快捷筛选。旧文件拒绝覆盖，来源报告不变，输出不含完整账户身份、日记原件或整个冻结包。

另提供显式 `serve-review` 短时入口，启动只接受固定报告 ID 和受限生命周期，校验同一来源绑定后仅开放原文要点页、已保存改进项、目录及选中标的/日期/案例的必要白名单投影。只绑定回环地址；校验实际 Host、同源请求及会话边界，GET/HEAD、no-store、静默日志、无宽松 CORS、无任意路径/SQL/URL参数或目录服务。选择不合法时拒绝，不回退全量。不会读取或代理旧 HTML，不触发账户、行情、模型、账本写入。停机释放监听与内存状态。

这是新的有界查看能力，不是已有 file URL 拒绝的替代通道。HTTP、回环地址、脱敏和合成浏览器通过均不证明真实资料的工具准入；工具明确拒绝某次真实访问时保留原始拒绝并停止该路线。真实页面显示/切换完成需要允许路径上的实际浏览器观察，缺证据时维持未完成。

默认日 K，用户选择的起止区间连续展示，可跨年；年份仅作快捷填入区间。日期控件按材料实际可选范围初始化，明确缺行情和无成交，逆序拒绝。图窗前上下文最多展示90个日历日内的60根已冻结 K 线，允许跨年，有背景时说明日期与数量。窗口后只延伸到本次真实已知截止，缺行情不能补造。图表保留冻结 OHLCV 原价格口径，拆股/代码变更在当日面板独立说明。B/S/T 仅按日期关联，不表示成交价；无论行情复权口径是否已核验，面板保留券商原价并说明不作跨口径价位比较，成交价格不用于字母定位或调整价格轴。

成交日以当前筛选后的真实成交方向汇总：仅买为 B，仅卖为 S，买卖都有为 T；T 只描述同日存在两个方向，不证明回转配对或做T策略。方向未全部核验且无法证明双向时不生成B/S/T，操作面板仍保留所有事实和未知方向提示。每个存在对应冻结日 K 的日期仅在蜡烛中心显示一个字母，位置由该蜡烛决定，不代表实际成交价；不再显示箭头、成交数量框、引线、独立期权标记栏或事件菱形。原始逐笔时间和成交价在图内当日悬停面板及明细保留。期权只按交易所日期关联 underlying 蜡烛，面板列完整合约、买卖/已知开平仓、数量、权利金和乘数，权利金不进入标的价格轴。只有可靠历史期权 OHLCV 才提供合约价格轴。成交时间不精确时只定位交易日；盘前/盘后和夏令时不强行贴到常规 session。B/S/T 有简短文字图例，不能只靠颜色表达。

行情适配优先调用已有工具的只读数据接口，使用标的身份与日期，不携带账户引用或交易金额。结果冻结来源、时区、是否复权、session、公司行动与缺口。不存在可靠历史行情时保留时间线与成交表，不能生成合成 K 线补洞。

实机首次行情获取发现宿主 Python 没有可用默认 CA 包。重复使用入口只在 Mac 默认 CA 文件与目录都不可用、用户没有设置 CA 环境变量时，读取固定已存在的系统 CA `/etc/ssl/cert.pem` 并保持证书与主机名校验；不修改全局环境、系统配置、端点白名单或重定向拒绝，不新增任意 CA 路径与网络重试。环境仍无法验证时保存行情缺口，不破坏已入账成交。

港股来源代码可能包含五位前导零。公开行情查询仅在明确 HK/HONG_KONG/HKEX 市场、纯数字且数值在 1..99999 时，转换为至少四位数字加 `.HK` 的提供方代码；例如 `00006` 查询为 `0006.HK`，有效五位数保留。原始证券身份与期权合约不变，提供方返回身份仍必须精确匹配；未知市场、零值及越界不猜测、不查询。

### 7.1 图表视窗和筛选状态分离

在现有 SVG/原生 JavaScript 中增加小型视窗状态，不引入远程图表库、框架或后台。范围筛选决定可访问的冻结记录和行情；可见时间轴决定当前绘图区，价格轴仅按可见冻结 OHLC 调整。首次选择及重置适配整个范围；滚轮以指针时间为中心缩放，拖动横向平移；提供放大、缩小、左右移动和重置按钮，使触控板或无滚轮用户也能操作。时间轴有明确最小跨度和冻结范围边界，边界不发起行情请求。

蜡烛、B/S/T、焦点及图内当日面板共享同一时间变换及绘图区裁剪，不能只放大整个 HTML 或增加容器滚动条。视窗之外的记录不删除；从复盘跳转成交可移动视窗使目标可见，点击仍使用隐藏原始定位身份。缩放/平移不重置当前案例、已打开讲解、日期明细或统计；改变标的、案例或筛选区间才适配相应新视窗。跨年、无行情但有成交、同日密集标记、期权、边界及窄屏纳入受影响验证。

“全局”覆盖这两个独立 Skill 的全部用户阅读出口，不扩展无关 Council 或现有产品网页。图表、离线合并页、已有只读查看投影、新生成中文 Markdown 报告及 Skill 交付文字共用易读标签：成交用证券/日期时刻/买卖/数量，案例和练习用原标题，资料用来源名/资料标题/发布时间，覆盖及精度用中文说明。hash、内部身份、私人路径、JSON、技术版本字符串及枚举不放在默认或折叠阅读区、提示和打印内容。确有用户意义的报告日期、数据截止、价格口径、当时/事后/不确定层和缺口继续显示。

页面分别标注当前图窗与报告依据范围，不能因日期操作把旧统计/结论当作重新计算。此次只改善日期与阅读操作，用户关于复盘缺口的询问以实际报告审计回答，不顺便实现账户收益引擎、期权反事实、长期能力评分或练习追踪系统。


### 7.3 蜡烛悬停与结论优先展示（已获实施授权）

主界面顺序为简洁标的/日期控制、图表、复盘总结、改进建议。顶部不再铺指标计数、覆盖面板、进度、目录和长使用说明；详细信息进入默认折叠的“数据说明/来源”，重要判断限制仍紧随对应原文显示，不能删除未知意图、时点精度或不可计算限制。

悬停绘图区内真实蜡烛（含影线、实体及同日字母）时，在图表内显示该日 OHLCV 及当前筛选后的全部操作：真实时刻、买卖、股票/ETF或完整期权合约、数量、成交价或权利金、费用和精度。面板不可把期权权利金写成股价，也不能将委托/行权/到期伪装成普通买卖。没有成交的日K仅显示行情及“当天无已保存成交”。同日多笔使用完整计数和面板分页，不能默默截断。

临时悬停与点击固定分别保存状态；移出清除临时内容，固定后可翻页和打开对应研究，Escape关闭，键盘焦点/Enter与窄屏点击提供等价操作。滚轮、拖动后日期匹配仍准确，固定日期及研究阅读状态保持；固定日期移出图窗时隐藏浮层并提供返回固定日期入口，回到图窗后恢复；拖动后不误触固定。无日 K、休市或日期不确定的成交不能吸附到相邻蜡烛，仍可在当日操作入口或明细读取，并提供局部短提示。

相关冻结事件不再单独画图标，在对应日面板内可逐项读取，并保留事件发生/资料可用角色、公开出处和逐笔当时/事后/不确定层；已知事件日但缺该日蜡烛时仍从本案事件列表读取，不因无蜡烛而丢失；不可定位资料继续在深入详情保留。

“复盘总结”直接投影 finding 的 pattern/process_observation/result_observation/interpretation，以及 lesson.practice 和已有 improvement_plan 的 exercise/next_inputs/verification；判断限制紧随正文。初始显示已有改进建议和按原保存顺序分页的研究原文要点，不能呈现空正文等待用户选目录。选择标的后显示该标的主样本相关要点和练习，不自动更改日期或图窗；选定日期时展示有明确成交引用关联的原文。标的仅是反例时明确标注反例关系并使用原 alternative_explanations.text，不能把另一证券的主结论贴给它。

当前报告没有全报告总评字段，不以 Python 排名、摘句拼接或条件规则生成新整体结论。全部138个已有案例和5项改进建议保留可发现性，研究原文不改写；仅按原顺序分页和显式事实关联展示，不给主观重要性排序。当前已有5项改进建议初始全部可读，无需先选练习或案例。finding主文按自己的record_refs关联，反例按对应alternative.record_refs，practice按自己的record_refs；跨发现/证券的plan保留原全报告或跨案例范围标签，不因命中finding_refs就冒称当前标的专属练习。详细三层讲解、反例、来源和计算按需展开。

按需查看器除现有选择投影外，需要明确白名单的全局改进项/原文要点页及当前标的主样本摘要；只返回此阅读所需文字与隐藏定位引用，完整证据/反例/计算仍经显式案例选择，不返回整个冻结包。初始为空及group选择findings空的问题须在投影层闭合，不能仅靠CSS或自动选中下拉掩盖。此增量只读旧研究、生成新展示产物，不重新采集、请求行情、运行模型、修改账本或突破先前真实浏览器拒绝。

### 8. 复盘资料把当时可知和事后结果拆开

独立 Skill 默认消费当前账本全历史，冻结一次完整输入，再做分批案例分析。公开事实与私人成交分别引用，不写回共享 Research Memory。公开资料缓存可复用只读合规接口，但不存在相应能力时使用普通只读检索，不新建历史数据平台。

LLM 根据实际交易选择相关宏观、市场/行业指数和公司事件；常见资料是央行政策发布、官方通胀/就业公告、发行人财报与公告，以及可核验的历史基准行情。不同市场选择相应官方来源与基准，不机械把所有成交都解释为美股宏观。资料包保存发布时间/可用时刻、事件发生时间、观测所属期间、检索时刻与版本。

交易当时资料切片 `available_at <= occurred_at`。当天日 K 的完整 OHLCV 和收盘、之后财报/政策以及宏观修订数据只能进入 outcome 层；精度不足的材料标为不确定，不用于日内推断。全图可以展示后续结果，但当时观察层有明显 cutoff。宏观 vintage 缺失时说明无法恢复当时读数，不使用今天修订值解释当时判断。

保存可选的用户交易日记/计划，以原记录时间区分当时计划和后来补写；用户没有提供时，仍可复盘可见事实，但不能代写原始动机。来源文件、新闻和导出中的指令文本都视为数据，不改变 Skill 权限或操作步骤。

### 9. 当前 Codex LLM 负责解释，工具负责全部金融算术

不添加 Python 调用模型或自动重试。当前会话的 LLM 阅读冻结包，先概览全部可计算交易，再选有理由的成功/失败/边界案例；用确定性工具获得 episode 统计、明确窗口的比较和反事实结果。后续需要更长分批或额外模型运行时，遵循用户已给预算，不为普通复盘启动 Runtime Eval/Smoke。

报告包含范围与限制、模式观察、成交与图表引用、当时背景、决策过程与结果、替代解释/反例及少量练习。LLM 可以提出候选模式，不能由工具规则先决定“追涨/冲动/纪律差”，也不输出综合能力分数。期权无历史 IV/Greeks 时只说明哪些敏感性可能相关，不能重建不可得数值。

每条改进项保存对应证据、练习行为、下次需记录的信息、复查方法和窗口；例如先记录原始 Thesis/失效条件，再检查是否按计划退出。它不是对当前个股的买卖建议，不自动改 Skill、策略或风控。

图表讲解使用 `TradingReflectionReport/1.1.0` 的 `case_lessons`，输入包继续为 1.0.0，旧 1.0.0 报告只读兼容。每条 finding 对应一条 LLM 讲解，包含真实主样本焦点、起止日期和证券 key、三层讲解及事实引用、事件引用与锚点角色、限制；覆盖不全不得保存为新版完整报告。时间从已冻结 available_at/event_at 派生，不使用 as_of 充当事件日；缺可靠定位的事件留 UNPLACED。事件对每笔记录展示 contemporaneous/outcome/uncertain，公开可得不等于用户阅读。指数无完整冻结序列时只展示已有摘要，不伪造曲线；期权无历史合约行情时只展示标的路径和独立权利金事实。

显示层将当前标的同一可信日期的已关联事件放在当日图内面板，以完整成员数量和逐项入口读取；缺同日蜡烛时仍可从本案事件列表读取，不画独立事件图标。分组只按已派生定位日期组织界面，不去重不同事件/角色、不合并研究语义或信息集；单事件保持既有入口，UNPLACED与缺证券时区定位的资料继续保留在案例列表。

### 10. 真实使用与开发验收分开

apply 首先实现隐私隔离与离线合成纵向切片，使用合成导出和期权边界案例验证账本/图表，不打开账户。随后在用户主动启动的实际 Skill 请求内做一次已选期间的最小只读采集，确认导出与页面勾稽、重复导入、图表标记和实机动作拒绝；已有范围授权时不逐步重复询问。

真实 LLM 复盘验收必须明确单独的一次样本/检索范围和预算。它验证独立 Skill 的内容质量，不复用“测试 PASS”声称语义已验证，不调用产品 Runtime 模型入口。未取得实际 GUI 证据或 LLM 报告时，对应任务维持未完成。独立复核只读取脱敏差异与已有证据，不读原始身份材料或自行启动账户/模型。

## Risks / Trade-offs

- [Mac 控件不暴露、地区/版本菜单不同] → computer-use 用当前 AX/截图识别只读路径，动作后核验；无法确认下一步时停止相关动作，用户辅助导入保留来源区别，不代替自动采集完成。
- [账单只有日级或订单汇总] → 保留精度和原始语义，可在正式成交详情补取；不能生成不存在的逐笔时间/价格。
- [私人目录随 product 被复制] → 首次写入前完成 Git、模型复制、插件来源/缓存与实际发布副本哨兵检查，不依赖未证实 ignore 机制。
- [老历史与期权行情不可得] → 完整保存已读取交易，披露类别/期间和行情缺口；不采购数据或补造历史。
- [重复同价成交被误去重] → 优先源成交 ID，保留来源行身份，不能证明重复就保留疑问并限制统计。
- [事后结果影响过程判断] → 当时资料与 outcome 分层，明确发布时间、用户意图未知与反例，禁止用最终盈亏直接评分。
- [长历史检索与上下文成本扩大] → 全历史确定性汇总、资料缓存、透明案例选取和有界分批；保存未分析清单与进度，不建立自动循环。

## Migration Plan

1. 先增加新能力的私人目录隔离与合成哨兵检查，修复相关复制入口，并验证洁净插件副本；任何真实账户材料暂不写入。
2. 创建两份 Skill、最小辅助模块、版本登记与离线合成导入/账本/图表。保留既有 Tiger API Change 及其账本限制。
3. 在用户实际 Mac 优先以 computer-use 验证只读页面与官方导出，登记脱敏工具观察；native 另登记验证过的固定配置。通过隔离与所选期间后才保存真实材料。
4. 加入冻结公开资料与 LLM 复盘提交/版本化，在明确样本预算下验证报告与反例；独立评审实际证据。
5. 关闭新 Skill 即停止采集/分析。回退代码不会删除私人目录；继续保留其 ignore/复制排除，不能因回退把历史隐私重新纳入插件或模型。

## Open Questions

- 用户实际客户端 bundle、版本、地区、界面语言、可识别控件、正式导出格式、最早历史日期及期权字段：由首个 apply 实机切片记录，未知只影响适配配置与覆盖状态，不改变只读/降级边界。
- 实际各市场行情提供商能返回的最早日期、复权与 session，以及官方宏观历史发布版本可得性：按标的与事件记录缺口，不以资料全齐作为所有交易保存的前提。

### 12. 持续本机工作台与资料刷新（已获规划更新及 apply 授权）

主入口为显式启动的 `serve-journal`，默认 `127.0.0.1:8765`，一直运行直到停止；端口冲突明确失败，测试允许随机端口。旧 `serve-review` 保留固定版本和时限。无开机配置、自动账户任务或第二个LLM编排器。页面只访问固定本机API，不代理已有私人HTML。

账本、当前行情时间线、已保存复盘是分开的版本轨道。最新时间线从同一账户全部当前记录及匹配、校验过的快照构建；不能因最新批次区间较短遗漏旧交易。资料重载使用当前请求线程自己的只读Ledger连接，按已验证的snapshot/report业务身份及保存记录选择版本，不按目录mtime。发现新复盘后仍用其原packet/snapshot，不能用新K线或成交换绑旧结论。页面分别展示交易业务截止、K线截止和复盘依据截止，以及未纳入复盘的记录；旧版可选。

页面保留B/S/T、悬停与固定、缩放和平移。刷新完成尝试保留标的/完整合约/日期/图窗/固定日；选择失效时明确重置。最新交易图与原报告正文分别呈现；选择案例时可进入原冻结图，不将不同快照伪装成同一输入。新图表和历史报告可随时保存为静态历史产物。

GET仅查询状态、图表和明确报告/案例白名单投影。POST仅固定的刷新资料、更新K线和导入官方CSV；要求精确Host、同源Origin、会话Cookie及CSRF证明，拒绝任意路径、SQL、URL、Shell、模型或账户动作。写动作串行且有界，繁忙时不叠加；失败保留旧可读状态。body与上传有上限，原始官方CSV仅存私人sources且不回显身份，不提供原始文件下载。日志不包含请求体、券商身份或原交易正文。

公开K线更新仅由点击触发，证券来自所选账户事实、日期限定冻结范围与今天；无任意URL或账户字段。使用既有行情适配器和来源/复权/时区/公司行动校验，新行情形成子快照；同一标的期权复用标的行情，不把权利金放上股价轴。网络失败/部分失败不删除旧有效行情，未收盘蜡烛不升级为当时已知收盘。刷新行情不运行LLM、不改旧统计或研究判断。

官方CSV导入仍要求账户及完整起止日期，来源标为用户辅助。稳定成交ID可沿用revision准入；相同来源文件重复导入不增加成交。没有稳定成交ID的不同重叠导出不能按同秒/同价/数量简单合并：新入口对重叠且不可核验身份的交易批次在写入前拒绝，提示选择不重叠窗口或使用可证明来源；费用更正及同秒不同真实成交不猜测去重。只允许新入口明确的新事实追加，不追溯改写旧账本/报告。成功导入创建全保存范围的新快照，保持旧行情可读，新证券缺行情明确显示。

网页提供更新交易/重新复盘的真实使用说明，继续由当前Codex会话Skill或用户选择CSV完成；没有会话桥时不展示假装能自动操作券商/调用LLM的按钮。本次不执行新的真实采集或研究；真实公网行情点击行为按用户明确动作运行。实际本地部署可以加载已存资料，但不能为浏览器验收换协议绕过此前私人页面拒绝；只用虚构材料进行工具浏览器检查，真实绑定、旧文件和健康状态另验。


第12节导入细化：页面固定上传字段为 `csv_base64/start/end/source_timezone/range_timezone`，原始 ArrayBuffer 经严格 base64 编解码保留原文件字节；解码后限4MiB，总JSON限6MiB，不接受路径或URL。范围时区从香港、美东、UTC显式选择；成交来源另允许仅正式账单的PER_ROW，混合时间不通过账户地区猜测。跨文件准入在预检及写锁内按统一窗口复核，包括未知起点的开放区间和跨来源时区。来源写入、成交revision与全范围snapshot属于同一数据库事务；失败时在写锁释放前清理仅此次新建原始来源，已有来源保留。
