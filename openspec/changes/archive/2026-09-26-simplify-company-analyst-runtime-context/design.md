## Context

见 proposal.md。历史实现、五次研究、hash 与失败原因见 [基准记录](../../../../reviews/development/simplify-company-analyst-runtime-context-baseline.md)。第五次真实字段查询已交付收入、净利润、经营现金流、资本开支的全期间事实；完整财年 EPS 未查询，草稿的无支撑 Claim 被原 Schema 拒收。

用户现已批准回退并授权调整为可接受的收尾目标。以下是当前决策，取代原阶段 Profile 上线计划；原质量验收失败不改写。

## Goals / Non-Goals

**Goals:** 结束无收益证明的模型重试，恢复原完整 Company 配置和研究任务说明，留下有实际使用证据的字段查询及必要契约提示修复，保存整体复盘和可复查的回退检查。

**Non-Goals:** 不声称消减成功、质量无退化、原工程全面失效或新组合完整 Smoke 通过；不扩大预算，不修补模型草稿、不放宽 Schema、不迁移历史报告、不修改共享 Skill/其他模式，不新增 Agent、编排器、排名或自动投资判断。

## Decisions

### 1. 区分基础工程缺点、实现缺陷和未证实的因果

- 原配置混合普通股、多维、研报发现及历史 Council 职责，是真实维护负担；目录 272 组/844 条、约 199402 字节，占旧 packet 约 89.8%，是更大的输入负担。
- 原按 ID 查询增加同字段全期间获取成本，无附件却展示附件入口属于确定性提示/授权不一致。这两点已得到局部修复。
- 数据存在、目录交付、字段工具执行、模型采用、合格报告是不同环节。第五次证明字段工具可用，但没有证明模型必然选择完整 EPS。输出 Schema 正确挡住无支撑 Claim；它没有造成该 Claim。
- 精简配置仍写有“每个 Claim 至少有一项合法支撑”和缺口前查询要求，因此不能简单断言删除一条提示导致第五次失败。现有受限比较没有控制所有父线程设置和运行环境，不能作消减的因果证明。
- 工程验收前期过度追求宿主不提供的原生有效指令回执，后期又把有限上下文实验与多个研究质量问题绑在一起，导致范围与模型成本扩张。局部测试证明接口，不证明 LLM 研究可靠性。

### 2. 明确回退范围

普通股绑定常量指向原完整配置，Agent 版本恢复 3.0.20，hash 与该文件一致。完整配置启用五项 Skill，其中研报 Skill 原本已启用；普通股 manifest 仍记录其原先必需的四项研究 Skill。恢复原先“包含四项必需能力、无重复”的校验，允许完整配置为其他模式启用额外 Skill，不误用精简 Profile 的“四项文件配置”限制而阻止启动。

恢复原动态研究任务说明，保留三个必要增量：字段查询的短说明；只有本次有附件授权才出现附件入口；财务期间与来源元数据、计算 ID 闭合的已识别歧义修正。保留原只读授权、隔离副本/绑定检查和用户配置隔离。恢复后不再宣称指令缩减收益。

实验 TOML 保留原字节供审阅，但运行选择器和启动命令不指向它，也没有重新启用开关。其他模式继续原配置。旧运行按当时 hash 读取，旧 prepared run 绑定不匹配仍拒绝，不能为恢复兼容改写历史。

### 3. 保留小范围查询成果

沿用当前 query 的单一精确 semantic_field 与 evidence_ids 二选一，范围为目标证券/Gate/request/Company 目录交集。返回全部获准期间及修订原事实；超 65536 compact UTF-8 字节整次拒绝。普通股 Adapter 2.4.0、其他模式 2.3.0；实际交付 ID/hash 供原引用校验使用。第五次字段调用的 input_hash 已按服务端规则重算匹配，是接口真实使用证据，不是整份报告成功证据。

### 4. 收尾证据与边界

聚焦测试验证完整配置绑定、隔离启动选择、技能集合、错误配置拒绝、其他模式兼容，以及字段查询/附件授权/Schema/PIT/引用边界。复用已有旧完整配置成功研究和第五次字段工具事件，明确本次回退只作零模型验证；五次额度已用完，没有回退后新的整体真实 Smoke，也不把这些局部证据拼成一次完整成功研究。

原 3.2f（新 Profile 内容质量）结果为 NOT_ACCEPTED，原 3.3（内容通过后的独立验收）未启动。本次实验结案交付只证明回退和局部工具能力，不能用新目标给旧目标补 PASS。独立收尾复核与明确归档批准仍是正式同步归档前的流程，不再以第六次研究作为自动前置。

## Risks / Trade-offs

- [恢复完整配置仍可能出现资料遗漏或格式错误] → 明确没有可靠性保证，继续使用原拒收与失败状态，不补写模型输出。
- [保留字段查询但误称整体研究质量已通过] → 独立记录工具交付与报告终态；第五次研究仍 FAILED。
- [历史任务改写为已通过] → 原十项完成、两项未通过/未启动的状态保留于结案记录，当前任务只核对新授权的回退范围。
- [进一步工程化] → 目录设计、覆盖评估、格式修复闭环和模型对照仅作后续建议，不在本 Change 实施。

## Migration Plan

恢复普通股默认配置及原研究说明 → 核对必要工具增量 → 聚焦确定性测试 → 记录受限结案结果。2026-09-26 用户明确批准记录问题后归档；独立只读收尾复核允许受限结案。按该授权同步实际保留行为、归档并仅提交推送本 Change，详情见 closure.md；不宣称消减上线或回退后真实 Smoke 通过。
