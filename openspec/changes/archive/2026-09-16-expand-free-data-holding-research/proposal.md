## Why

当前已完成普通股公司研究首版，但仅凭基本面不足以支撑后续投资判断。按用户最新方向，先扩充免费资料支持的持仓研究维度，再接独立反证 Agent；以有实质内容的研究交付为终点，避免无限采集或扩建工程平台。

## What Changes

- 按顺序交付：范围与首阶段来源 → 价格成交量/技术结构 → 基本面深化与公司事件 → 自动获取、读取与对比研报 → 行业比较 → 宏观市场环境 → 机构/内部人披露 → 期权及可验证资金行为 → 多维研究交接。各维度来源在该阶段开始时核对，不以全部来源检查作为首阶段前置。
- 研报从持仓和核心问题自动发现、获取正文、核实来源时间、提取并对比，用户上传仅为可选补充。区分事实、转引、观点、预测及估值假设，正文不可得时不声称读过报告。
- 补充逐公司核心问题清单、实际数据生成的量价/相对表现图、可得管理层指引变化、公司相关行业变量和多维摘要。
- 明确各维度最低必答问题、条件适用项和缺口出口；研报必须说明对已有判断的支持、挑战、修订或无新增信息，记录已披露利益关系及未知状态。
- 开发按阶段交付，产品运行按实际依赖有界并行并及时展示已完成报告。资料准备步骤由现有研究角色调用显式授权的只读搜索/正文工具，正式分析只消费 Gate 合格资料，旧模式权限保持不变。
- 每项明确 Input、Tool/Data、Skill/Reasoning、Structured Output、Eval；优先扩充 Skill，按真实职责绑定现有 Agent，不按股票或数据源创建 Agent。
- 承接已确认持仓，普通股逐证券研究，市场资料共享；保留 ETF/期权持仓未覆盖状态。研究普通股的期权链不代表具备用户期权持仓分析能力。
- 免费、非实时、日线为默认；用户未给持有期限时并列呈现近期及中期观察窗口，不猜测交易风格。来源实时可用性在实施阶段有限实测，不因开源 SDK 存在就宣称资料可用。
- 每阶段独立交付中文与结构化报告、限定检查及实际研究证据；核心阶段不能仅凭缺口关闭。研报、所有权和期权/资金的外部资料确实受限时，明确延期范围及未验证能力，按用户已接受原则集中提交最终验收，不无限阻塞后续 Skeptic。真实批次每只普通股、每个维度都保留结果或具体缺口。
- 收尾时形成一个 canonical 下游交接包：以同一基础 run、组合绑定和 decision cutoff 为准，纳入已有且兼容的 EquityResearchReport，并只在重新验证绑定、时间和 Evidence closure 后引用补充报告。不同 run 或不同 cutoff 的补证只能作为能力验收证据，禁止静默拼接成同一次用户研究。
- 将“Schema 可解析”与“下游就绪”分开判断。缺少公司研究引用、补证未绑定、引用未闭合或跨维度待反证问题未明确时，可以保留结构化产物，但不得声明已经可直接交给后续 Agent。
- 用户已接受将公开研报正文深化、13F 两期机构持仓及期权/资金真实快照延期至 `capture-futu-client-research-data`；本 Change 保留明确缺口和责任归属，不把延期写成能力已实现或研究已验证。
- 暂缓 Skeptic 接入；不在本 Change 实施 CIO/Risk 新决策流程、发现新股票、券商交易、付费数据或治理平台。

## Capabilities

### New Capabilities
- `multi-dimensional-holding-research`: 普通股多维研究的阶段目标、来源边界、研究方法、交接和有限验收。

### Modified Capabilities
无。以显式新增研究阶段扩展，原 `COMMON_STOCK_RESEARCH`、EquityResearchReport 和其安全约束继续保持；不把旧阶段偷偷变成完整组合分析。

## Impact

- 复用 `product/runtime/common_stock_data.py`、现有研究派发与宿主入口、`product/mcp/live/` 数据及缓存、既有 Schema/引用/PIT 检查。
- 扩充 `product/skills/` 专业方法、必要的只读数据与确定性计算；新增多维研究包及同源中文展示，保留旧公司报告。
- 收尾阶段仅做必要的确定性归集、绑定和消费校验；不得用 Python 补写新的投资判断，也不因组装交接包重新运行无关 LLM 批次。
- 延期能力由 `capture-futu-client-research-data` 承接；该 Change 的存在不构成本 Change 已取得对应数据或完成对应研究的证据。
- 实施时更新 `PRODUCT.md` 当前优先级和产品说明，使其反映用户批准的新顺序；本轮仅写规划。
- 现有 `us-equity-live-advisory-slice` 继续暂停。当前公司研究依赖部分未提交 live 文件，实施开始需记录实际依赖与改动归属，不能以本 Change 完成为由关闭旧任务或夹带发布。
