## 1. 基线与并行边界

- [ ] 1.1 从已验证 MRVL 冻结运行只读记录各报告、准备包/Prompt、工具日志实际保留的 `read_reports` 返回、短引用模型视图和事件体量，并核对文件/事件 hash；缺原始返回时将按 hash 重建的候选体量另列，交付分层口径表，不把重建或生成但未交付的视图计入实际输入。
- [ ] 1.2 从可观察的父/子调用记录提取输入/输出/cache token、延迟及实际可得费用，参考 tokenizer 估算另列；核对不可观测项和成本口径并提供可复算结果，不推断总账单。
- [ ] 1.3 依据基线预登记索引尺寸上限、完整性覆盖清单、质量评估维度及候选对照预算；验证清单包含所有现有报告类型、重要反证/冲突/缺口，预算须在任何真实新模型运行前另获用户明确批准。
- [ ] 1.4 在编辑共享 CIO 代码前重验 `enable-single-stock-research-synthesis` 的最新状态与该接缝差异，确认没有活跃 ALB 执行/冻结重签，并核对 Tiger 独立目录不在变更清单；若仍活跃则停止共享代码实施，仅保留只读分析。

## 2. 版本化 CIO 交付

- [ ] 2.1 为新 CIO invocation/准备包绑定显式交付版本并保留未声明版本的原读取语义；通过旧 MRVL、当前单股请求和未知版本拒绝的准备/消费者测试验证不改旧锁。
- [ ] 2.2 从获准且 hash 校验的原报告生成逐份有界结构化索引与稳定详情定位，覆盖结论、支持/反证、假设/失效、冲突、计算、单位/期间、来源角色及缺口；通过各报告类型字段覆盖测试和索引超限/不可安全投影回退测试验证原报告字节不变。
- [ ] 2.3 在 `research_reports.read` 既有权限内实现精确索引及原报告全文读取，细节选择仅在可证明字段与引用闭合时启用，否则选中报告读全文；通过未知 ID/片段、路径逃逸、hash漂移、跨运行/身份错误及短引用映射正反例验证。
- [ ] 2.4 仅为新版 CIO 调整可信 Prompt 及工具说明，要求先读取全目录索引，再对采用的报告/反证读实际细节或全文并查询最终 Evidence；以真实工具返回和绑定测试验证非仅改 Prompt，旧版本仍要求全目录全文读取，独立 Skeptic 首轮输入不含内部正向内容。

## 3. 消费证明与确定性回归

- [ ] 3.1 按冻结版本重建并验证工具返回事件：旧版继续要求全部获准报告全文已读；新版区分目录授权、逐份索引交付、细节/全文读取和模型 `report_selections`，无可验证细粒度选择时要求选中报告全文；以历史原包及新旧伪造/缺失事件负例验证，不回写任何历史原件。
- [ ] 3.2 对新版输出重验被采用报告的细节或全文绑定、实际 Evidence 查询、引用闭合与研究级 Schema；以未读取就选择、跨报告引用、缺反证、索引内容漂移及 `PORTFOLIO_ADVICE` 模型前拒绝的用例验证，不能由自然语言自报补消费事件。
- [ ] 3.3 在 ALB 单股 Change 稳定后跑受影响 CIO/单股/旧持仓/短引用/独立 Skeptic 的接缝回归，并核对版本镜像与 OpenSpec strict；保留测试日志及原运行 hash 对比，任何失败不记为通过或转化为研究质量证据。

## 4. 有界对照与启用判定

- [ ] 4.1 用户另行明确批准模型、次数和预算后，基于同一冻结资料和锁定问题/模型构造彼此独立的原交接与候选交接运行；逐项核对来源/报告/版本绑定、实际工具返回、父子 usage 与停止条件，不复用或改写 ALB 失败包。
- [ ] 4.2 对成对结果按预登记清单复核重要事实、正反分歧、冲突/资料缺口、可解析引用、CIO 自主取舍和研究级边界，并分列输入 token/缓存/延迟/可观察费用；交付逐项对照及未观测范围，不用 Schema 通过或字节变小代替质量证明。
- [ ] 4.3 只有质量不退化、消费证明闭合且可观察效率改善时才提出候选启用；通过新运行启用/失败停止及后续新运行回退到旧版本的测试验证历史包各按原版本读取，未获批准或评估不足时记录保持旧交接且不晋升。
