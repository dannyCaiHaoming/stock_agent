## 动作复盘

BUY 与后续结果一致，但结果本身不证明当时的预期收益可确定。回放报告明确写出从试探仓加到标准仓的条件：Q1 达到公司指引，之后 Cloud Memory 保持强劲且 Core Data Center 不再同比下滑。

这一条件在 FY2026 Q1 业绩公告中已出现：收入 $13.643B、毛利率 56.0%，高于原指引；Cloud Memory 营业利润率为 55%，Core Data Center 收入同比转增。按 `forward_returns`，从 2025-12-18 起算，MU 随后 63 个交易日总回报 +62.75%、超额收益 +65.32%；126 个交易日总回报 +323.51%、超额收益 +314.17%（Yahoo 价格，截至 2026-10-15）。这说明报告提出的加仓条件随后出现，且出现后股价继续显著上涨；并不意味着当时必须知道之后的涨幅。

**过程错误：未发现有明确证据支持的重大错误。** CIO 识别了已披露的加速和明确指引，同时把周期、估值及现金回报风险用于限制仓位。**结果噪音／机会成本：** 试探仓参与了上涨，但其规模可能低于事后最优规模；仅凭上涨幅度，不能把谨慎仓位认定为过程错误。  
**估值情景偏差：** 回放情景最高假设 FY2026 收入 $58B、营业利润率 42%；之后报告的 FY2026 实际收入和营业利润率分别为 $133.188B、74.6%，远超全部情景。原报告已说明情景依赖主观假设且不是目标价，因此这是经营路径估计失准，不应倒推为当时可确定的买入信号。

## 当时可得、事后证明有效的信号

- FY2025 收入和营业利润率已经从低谷恢复；FY2025 Q4 收入、利润与毛利率继续上升，FY2026 Q1 指引进一步增强。后续连续数季超过前季指引，说明经营加速信号确实重要。
- Cloud Memory 当时已有高毛利、高营业利润率的实际贡献；后续数季高利润率持续，支持将它作为增长质量的证据。
- MU 在回放日前已显著跑赢 SPY。它确认了市场趋势与基本面方向一致，但不是能单独预测超额收益幅度的信号。

## 当时可得、事后证明误导的信号

- **Core Data Center 单季同比下滑**是真实风险，但作为全公司反转的代理会产生误导：下一季度即转为同比增长。回放报告将其保留为风险监控项是合适的。
- **FY2026 全年收入与利润率情景**过于保守，后续指引和实际结果一路大幅上移。回放时的全年收入与利润率没有公司全年指引支撑，不能说当时必然应预测到实际规模；可改进之处是每次指引大幅上修后及时更新情景，而不是长期沿用初始假设。
- **低 FCF yield 与高资本开支**提示了现金回报风险，却没有预示现金流不会改善。后续经营现金流与资本开支均显著增加，证明不能用单一时点的 FCF yield 取代对资本投入回报和现金流构成的跟踪。
- 估值偏贵的担忧没有阻止股价继续上涨，但本案例无法证明估值风险失效；它仍是限制确定性与仓位的因素，而非短期方向信号。

## 教训（n=1）

- 当周期行业已出现**已实现收入和利润率加速，且公司近期指引继续上修**时，应更重视经营数据的连续验证，用局部业务走弱降低信心或仓位，而不应单独据此否定全公司复苏；本例 Core Data Center 一季下滑后转增，随后多季超过公司指引。**适用条件：** 公司指引可核实、业务分部数据口径可比，且后续财报持续确认。**反例风险：** 周期拐点可能快速逆转，连续增长也可能由供给紧张或客户预付款推动，不能据此无限外推峰值盈利。
- 当新财报连续显著超过上一季指引时，应及时更新收入、利润率和估值情景；本例原 FY2026 情景远低于后续实际结果。**适用条件：** 新信息来自已发布财报或指引。**反例风险：** 不应把一次超预期直接年化，也不能用事后结果声称当时即可预知超周期规模。
- 回放日明确写下的加仓条件有助于区分过程与结果：本例条件在 Q1 公告后出现，随后股价继续上涨；是否按条件加仓，仍应结合届时价格、估值和组合风险重新判断。**适用条件：** 条件具体、可观察且在决策前记录。**反例风险：** 价格上涨不能替代对估值和仓位风险的复核。**n=1**
