# 复盘：ADBE，回放日期 2025-07-01（组别：loser）

## 结果

回放动作是 **BUY / 中等信心**，分析期限 12–18 个月。用 `forward_returns`（Yahoo 价格，`as_of` 2026-10-13）计算，之后 63 / 126 / 252 个交易日 ADBE 总回报分别为 **-10.04% / -10.10% / -43.96%**，相对 SPY 超额收益分别为 **-18.19% / -21.96% / -65.88%**。一年结果与买入动作明显不一致，但尚未覆盖完整的 18 个月判断期限。

## 动作复盘

一年相对超额收益为 -65.88%，与 BUY 结果明显不一致。报告已经看到当时 ADBE 过去 252 日相对 SPY 落后 42.7%、收盘低于 200 日均线约 11.4%，也指出保守情景不是下行上限、估值历史数据冲突、AI 增量收入未单独证明。这些都是 **当时已知的风险**，不是事后才出现的信息。

因此，较有根据的过程问题不是“没有预测到之后的股价”，而是这些信号虽然被识别，却没有充分提高买入所需的证据门槛。报告接受了 skeptic 对情景下行覆盖不足、期限错配的提醒，仍保留 BUY；结果显示，对经营质量的肯定压过了相对弱势与估值不确定性。股价后续路径的具体原因无法由本次材料单独确认，不应把某个未核实事件认定为下跌原因。

报告已是 BUY，故不存在“等待转为 BUY”的条件。与之相关的验证条件后来出现：FY2025 指引兑现并超过原指引上沿，ARR 增长也延续。但从 FY2025 Q4 业绩发布日 2025-12-10 起，之后 126 个交易日 ADBE 回报为 **-40.54%**，相对 SPY 超额收益 **-49.04%**（`forward_returns`）。经营条件兑现后，股价表现仍差；这表明这些条件适合验证经营 Thesis，却不足以作为股价已具吸引力的信号。

## 当时可得、事后证明有效的信号

- FY2025 Q2 收入、Digital Media ARR 和公司上调指引确实预示了后续数季仍有两位数收入增长。它们是经营增长的有效信号，但不是相对收益的有效保证。
- 过去一年显著跑输 SPY、低于 200 日均线，是当时已有的风险信号。复盘结果强化了对此类持续弱势的重视，但单个案例不能证明技术弱势必然预示未来下跌。

## 当时可得、事后证明误导的信号

- “强现金流 + 两位数订阅增长”被当作足以支持小仓位 BUY 的组合信号。后续基本面仍强，但回报很差；把经营韧性等同于买入时点或股价安全边际，事后看具有误导性。
- FY2026 收入和利润率情景提供了明确的目标价，却没有可靠估值历史作支撑，也没有为大幅低于保守情景的结果设边界。目标价的精确度容易高于输入假设的可靠度。

## 教训（n=1）

- **在**公司增长和现金流良好、但股票已持续大幅跑输大盘且低于长期均线时 → **更重视相对弱势对入场时机和安全边际的约束** → 本例中经营指标持续兑现，252 日相对超额收益仍为 -65.88%；适用条件是趋势弱势持续且估值证据不稳，反例风险是价格可能在基本面改善前先行反转。
- **在**关键投资逻辑依赖尚未单独证明的 AI 增量收入时 → **更轻信未经验证的增长情景，要求可观测的客户扩容、留存或收入转化再提高动作强度** → 本例 AI-first ARR 后来披露并增长，但规模尚不足以由这些事实单独证明利润贡献；适用条件是新产品对长期增长主张重要但收入披露有限，反例风险是较早的方向性指标可能先于财务披露反映真实价值。
- **在**保守情景明确不是下行上限、而估值历史序列又有冲突时 → **把情景价格当作条件推演，不当作风险收益完整覆盖的依据** → 报告识别了这两项限制，仍保留 BUY；适用条件是模型关键输入无法校准或尾部风险未覆盖，反例风险是过度折价可能错过经营稳定、估值快速修复的机会。单案证据，**n=1**。
