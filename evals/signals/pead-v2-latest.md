# 财报后漂移 v2（as_of 最新）

**状态：历史开发数据。** 2019–2026 年的财报事件此前都已看过，这不是未接触的验证集；结论不得当作样本外证据。

口径：`evals/signals/pead-v2-definition-2026-10-26.md`。受理时间定信号日 D0，反应 = P 收盘到 D0 收盘的板块超额；D1 开盘入场，D_h 收盘退出（复权）；收益与路径最低点为个股相对板块 ETF 的超额；扣成本 = 减 0.2pp 往返。次日开盘是模拟成交假设。百分位与超额收益是两种口径，分开列。
CI（95%，1000 次，种子 0）：主要 = 按交易日期连续块（块长 h 个交易日）重抽样；敏感 = 块长 2h；辅助 = 按股票整群；单位为百分点（超额）或百分位点。结论（v2.1，依据相对基准超额的主要 CI）：CI 完全落在 ±0.5pp 内 = 效果太小；否则不含 0 为正 = 有增益证据、为负 = 有负向证据；其余 = 尚无法确认。相对基准超额 = 事件超额 − 同 D0 对照池均值（均按该池 1/99 百分位截尾；阶段分组用同阶段池）。原始均值超额与 v2 首轮结论保留作对照。
