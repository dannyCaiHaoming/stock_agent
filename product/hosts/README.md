# 原生宿主配置

公共研究方法在 `../skills/`，四职责正文在 `../agents/`。宿主目录只提供注册、发现位置、原生工具/权限与安装说明，不提供executor、模型SDK或统一事件协议。CIO由当前主线程承担。

| 宿主 | 配置格式 | Skill发现目标 | 当前状态 |
| --- | --- | --- | --- |
| Codex | 原生TOML角色/产品配置 | 项目`.agents/skills`或明确安装的产品Skill目录 | 遗留模板，未验收 |
| Claude Code | 原生Markdown角色、项目配置 | 当前仓库`product/.claude/skills` | 就地准备；实际加载和研究另验 |
| OpenCode | 原生Markdown/JSON角色与权限 | `.opencode/skills`、兼容`.agents/skills`等 | 遗留模板，未验收 |

这张表不是支持PASS。实际版本、原生委派、独立首轮、工具拒绝和主线程综合需各自有真实观察，不能用另一宿主的记录代替。缺最低能力时明确阻断，不启动另一个CLI兜底。

[产品准备说明](INSTALL.md)以Claude当前仓库`product/`就地入口为主，完整导出仅是可选分发。准备/刷新必须使用批准来源，未知同名内容写前拒绝；根开发`.claude/`、用户配置、认证和其他插件不覆盖。Model由宿主/用户选择，不把Prompt声明当实际切换，不默认评分或真实运行。

## 宿主前提与资料来源分开

Claude Code、Codex、OpenCode提供原生会话、模型执行、专业委派、等待及权限控制；本项目只提供共享Skills、角色正文和确定性业务工具，不实现第二套Agent执行架构。

OpenAlex是既有公开学术/技术文献适配器，不是Agent底座、模型服务或券商研报库。其正文配置仅影响使用该适配器的资料准备任务，不是三宿主安装、角色发现或冻结Gate公司研究的通用前置。缺配置保留具体资料阻断，不能扩散为整个原生包不可用，也不能跳过完整研究的真实依赖。新增或替换来源需另行批准，不为原生迁移自动注册、购买或配置外部服务。
