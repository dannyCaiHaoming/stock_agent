# 隐含预期：现价要求什么才算合理

## 回答什么问题
按当前价格，市场隐含了多高的增长、利润率或倍数？这个要求与公司的实际轨迹相比是偏高、相当还是偏低？如果实际结果偏离市场隐含的要求，上下行空间大约多少？

情景价值衡量的是一年以上的基本面空间，不是主窗口（60 个交易日）的价格预测。它用于决定仓位大小与改判条件，**不作为买不买的门槛**。

## 适用情境 / 不适用情境
- 适用：有营收与营业利润的公司。
- 不适用：亏损且没有利润率锚的公司（改用 EV/营收并说明局限）；银行（改用 P/B 与 ROE）。

## 数据要求
- 价格（`get_price_history` 截止日收盘）、股数、净现金（`get_financial_statements`）。
- `implied_assumption`：给定价格与收入，求隐含 EV/EBIT 倍数或隐含利润率。
- `pe_history`：自身历史 P/E 区间（注意拆股与口径）；同业倍数（`get_peer_snapshot`，回放中不可用）。
- `scenario_value` + `probability_weighted_value`：情景与概率加权空间。

## 分析步骤
1. 用最近的收入与利润率，求现价隐含的 EV/EBIT（或隐含利润率）；高增长公司再用下一财年的收入假设求一次，说明现价要求公司做到什么。
2. 与公司自身历史倍数区间、同业、最近的增长与利润率轨迹对比，给出一个判断：隐含要求**偏高 / 相当 / 偏低**，并写出依据的两三个数字。
3. 三个情景以“市场隐含的要求”为参照：
   - 中性 = 隐含要求大致兑现，价值接近现价（相对现价约 ±10% 以内）。中性情景明显偏离现价时，说明你认为市场错在哪个具体变量上，并给出证据；
   - 上行 / 下行 = 某个具体经营变量好于 / 差于隐含要求（写明是哪个变量、偏离多少）；
   - 倍数变化要有理由（增长换挡、周期位置、利率），不默认回到历史中位数；
   - 概率写依据。
4. 只用来衡量空间与仓位，不单独作为买卖理由。

## 输出口径
“现价隐含 EV/EBIT x 倍（或利润率 y%），历史区间 a–b 倍，隐含要求偏高/相当/偏低；情景 下行/中性/上行 = …，概率 …，上下行幅度之比 …”。概率加权期望可以列出，标注为“一年期基本面空间”。

## 对应统计
无（估值空间不是单一触发条件）：需要验证。

## 常见误用
- 中性情景默认把倍数压回历史水平，于是高增长或处于上行周期的公司一律得出负期望。
- 把一年期的价值缺口当作 60 日动作的门槛。
- 把低估值当作催化剂（盈利下修时，低估值后可能继续下跌）。
- 没有估值锚时让单一假设倍数决定动作。
