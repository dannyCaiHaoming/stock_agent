# 隐含预期：现价要求什么才算合理

## 回答什么问题
按当前价格，市场隐含了多高的利润率或倍数？这个要求与公司的实际轨迹相比是偏高还是偏低？上下行空间大约多少？

## 适用情境 / 不适用情境
- 适用：有营收与营业利润的公司。
- 不适用：亏损且没有利润率锚的公司（改用 EV/营收并说明局限）；银行（改用 P/B 与 ROE）。

## 数据要求
- 价格（`get_price_history` 截止日收盘）、股数、净现金（`get_financial_statements`）。
- `implied_assumption`：给定价格与收入，求隐含 EV/EBIT 倍数或隐含利润率。
- `pe_history`：自身历史 P/E 区间（注意拆股与口径）；同业倍数（`get_peer_snapshot`，回放中不可用）。
- `scenario_value` + `probability_weighted_value`：情景与概率加权空间。

## 分析步骤
1. 用最近的收入与利润率，求现价隐含的 EV/EBIT（或隐含利润率）。
2. 与公司自身历史倍数区间、同业、最近利润率轨迹对比：隐含要求是“已经超出过去最好水平”还是“低于现在水平”。
3. 三个情景：分别对应方向判断兑现、部分兑现、落空；概率写依据。
4. 只用来衡量空间与仓位，不单独作为买卖理由。

## 输出口径
“现价隐含 EV/EBIT x 倍（或利润率 y%），历史区间 a–b 倍；情景 低/中/高 = …，概率 …，加权期望 z%”。

## 对应统计
无（估值空间不是单一触发条件）：需要验证。

## 常见误用
- 中性情景沿用现价隐含倍数，于是“没有上行”。
- 把低估值当作催化剂（盈利下修时，低估值后可能继续下跌）。
- 没有估值锚时让单一假设倍数决定动作。

## 与其他方法的关系
回答 `growth-acceleration`、`guidance-revision` 的变化“是否已被定价”。
