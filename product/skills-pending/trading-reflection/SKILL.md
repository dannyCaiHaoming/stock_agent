# 个人交易反思

独立历史复盘模式，不担任 CIO，不要求组合 Handoff，不继承 Council 的 NO_TRADE 或 Runtime 工具权限。只消费用户已保存、明确选择账户的冻结记录；没有账本就说明需要先采集，不自动打开老虎。必要脱敏记录可以进入本次 LLM 上下文，原始账单/完整账户身份不能进入。

## 准备

使用 `scripts/journal.py --repo <已绑定的绝对仓库根> list` 定位账户/快照。默认全部已保存操作；用户明确子集才限定范围，说明缺口与未分析项。先生成/读取相同输入版本的 K 线，然后 `prepare-reflection --snapshot-id <id> --chart-ref <冻结图表引用>` 冻结统计与研究输入；公开证据及用户日记分别可用 `--evidence/--diary` 的结构化文件提供。字段见 [报告与资料格式](references/report-format.md)。

在用户范围与检索预算内，由当前会话 LLM 根据实际交易选择相关官方宏观发布、市场/行业指数、发行人财报公告和明确事件；不创建 Python 模型调用循环。公开检索只用证券与日期，不向外部来源发送私人成交。保存每项 `source_id/as_of/retrieved_at`、发布时间、可用时刻依据和版本，再准备新 packet。宏观历史修订不能当当时读数，当天未收盘的日 K/之后公告属于事后结果。精度不足或 vintage 不可得留不确定层。

## 分析

1. 先检查全历史统计、期初/费用/期权生命周期与行情缺口。金融算术由已冻结工具结果负责；引用 episode/summary/明确反事实计算，不心算金额收益。
2. 选择有理由的成功、失败与边界案例；记录选择原因与覆盖，历史过长按 packet 分批，不能只挑最亏交易或静默略掉标的。
3. 分析入场、加减仓、退出、持有和可见风险暴露。每个模式给具体成交、图表、当时背景、过程观察与事后结果，并保留反例/替代解释与置信限制。赢亏不直接等于过程对错；相关/先后不直接等于因果。
4. 原始意图只来自当时记录。没有日记时说明未知，不能猜恐惧、冲动或追涨动机；事后补写保持独立。期权无历史 IV/Greeks 不能补造，多腿和开平仓不能只凭成交时间猜。
5. 给少量证据支撑的练习：对应模式、下一次需记录的信息、验证方式和复查窗口。例如记录 Thesis/失效条件/持有计划再复查执行。不得给当前个股的新买卖指令、仓位或订单；不得自动修改策略、Skill 或风控。
6. 新版报告为每项 finding 亲自撰写 `case_lessons`：真实主样本焦点与图窗、初学读图和术语、候选错误与可验证练习、深入替代解释和推翻条件、限制。明确选取相关事件引用和锚点角色，时间由工具读取来源字段；只有发布日期不能推成 available_at，缺定位用 UNPLACED。期权焦点仍用真实完整合约身份，标的图不证明权利金表现。字段及版本兼容见格式参考，不能用程序模板生成解释或略掉未完成案例。

## 提交与交付

LLM 只提交 findings、improvement_plan、phase_coverage、analyzed_episode_ids、case_lessons 和额外限制等研究字段；用 `save-reflection --packet <冻结包> --research <研究字段JSON> --model-version <本会话实际模型>` 由工具装配身份/hash/Skill版本并验证保存。有 case_lessons 则保存1.1报告并要求逐发现完整覆盖，旧1.0报告只读兼容。不要重复手抄技术元数据，也不能用程序替 LLM 选择证据/改写语义。

保存后调用 `review-reflection --report-id <返回的报告版本>`，核验报告、冻结包及本地快照并生成合并查看页和新的易读文字产物。初始直接显示已保存的原文复盘要点及全部已有改进建议，选择标的或固定日期后显示按各自成交引用关联的正文；目录、覆盖、详细来源和计算按需展开，重要限制紧随结论；可搜索、恢复全部目录和切换，蜡烛只标B/S/T，悬停在图内查看当天全部操作和事件，点击固定；点击案例才主动定位焦点与窗口，普通标的/日期选择不自动跳转。起止日期可跨年，图表可缩放、平移和重置；当前图窗与复盘依据范围分别说明，图窗操作不重算旧结论或统计。事件保留逐笔当时/事后/不确定层，无完整指数序列不能补画曲线。已有报告/页面不覆盖，再次查看不重新采集、联网或调用模型。

用户明确请求本机查看器时可用 `serve-review --report-id <已保存版本> --lifetime-seconds 900`，只启动固定版本的短时回环只读投影，初始只取白名单原文要点页及已存建议，选择后取相关资料，结束即释放监听。它不代理旧HTML、不自动采集/分析，也不授予浏览器工具新的访问权限。工具已拒绝真实访问时停止该路线，不能换协议/通道绕过；合成验证与真实可视验收分别记录。

用户需要持续本地部署时，使用 `serve-journal --account-ref <已保存随机引用>`，默认固定回环地址 `http://127.0.0.1:8765/`，直到显式停止。工作区加载最新完整交易时间线及通过绑定校验的已保存复盘版本，刷新后保留当前图窗。交易、行情更新与这版复盘的原依据分别标明；新增或修订的操作显示“尚未纳入这版复盘”，不能把新行情静默换进旧研究。版本按验证后的资料截止与保存时间选择，不用目录修改时间。首次展示全部原文要点与建议；选标的/固定日期筛选关联要点，完整案例仍使用原冻结图表。要生成新复盘仍由当前会话 LLM 分析全量资料，保存新版本后刷新工作区；网页按钮只给真实调用方法，不伪装模型后台。启动方式见 tiger-trade-journal 的 [持续本地工作区](../tiger-trade-journal/references/usage.md#持续本地工作区)。

直接呈现已保存的观察、反例及改进练习，并保留易读中文报告。没有全报告总评字段时不由程序生成整体能力评价或主观排名；主文、反例和练习分别按自己的成交引用关联，跨标的计划保留原范围。覆盖说明按需展开，影响判断的限制紧随正文。交付文字使用交易日期、证券、动作、数量及案例/资料标题，不展示 hash、内部引用串、私人路径、原始 JSON 或协议代码；后台仍用原始引用校验，不能为美化改写金融数值或研究判断。已保存的旧中文报告不覆盖，需要新版阅读形式时只生成新的阅读产物。工具校验只证明结构/引用/计算一致性，不能冒称内容研究质量 PASS；打开请求已排队也不证明实际页面显示或切换正常。新输入或重新复盘创建新版本，旧判断继续可读；所有私人结果留本机，不上传 Space、Git、插件包或 Research Memory。
