# 使用与数据边界

入口为 Skill 自带 `scripts/journal.py`，源码可在仓库或插件缓存运行，数据根只由显式 `--repo` 绑定。读写分别由小型本地工具实施，不直接调用 Tiger OpenAPI。

```text
python3 <Skill路径>/scripts/journal.py --repo <绝对仓库根> window --period custom --start <开始日期> --end <截止日期>
python3 <Skill路径>/scripts/journal.py --repo <绝对仓库根> init
python3 <Skill路径>/scripts/journal.py --repo <绝对仓库根> import --input <私人sources内的官方CSV> --computer-use-receipt <私人sources内的观察回执> --new-account --period custom --start <先前window.start完整ISO时间> --end <先前window.end完整ISO时间> --source-timezone <核验的导出展示时区>
python3 <Skill路径>/scripts/journal.py --repo <绝对仓库根> import --input <官方CSV> --new-account --period custom --start <开始日期> --end <截止日期> --source-timezone <核验的导出展示时区>
python3 <Skill路径>/scripts/journal.py --repo <绝对仓库根> chart --snapshot-id <本次导入返回的snapshot_id> --fetch-market
```

新采集一次取得开始与截止日期，或由一周、一个月、半年、一年快捷填入；不再询问开户至今。日期包含首尾日，截止在未来时冻结至本次请求时刻，逆序拒绝。官方只支持按日查询时，可以取得边界日材料，但保存前按真实成交时间精确过滤；只有日期的边界成交继续标为不确定。旧 `lifetime` 参数及覆盖状态只作兼容，不推测或重新核实开户日。

官方 CSV 以实际列名核验；未知字段/只有委托均价不能冒充逐笔成交。支持英文与中文证券/类型/市场/币种/成交时间/数量/价格/方向/费用/成交ID等列，期权保留 underlying/expiry/strike/right/multiplier。完整账户号/姓名不写入规范化记录；缺资产分类保留未知，不能猜 ETF。

默认通过 [computer-use](computer-use.md) 进入历史并取得正式导出。用户未选期间时可以先找页面和日期选项；真实导出须在期间与私人隔离已确认后执行。客户端汇总表头中下单时间、状态更新时间不能当成交时间。已核验官方逐笔账单使用 `account_statement/PER_ROW` 回执，严格按每行的成交时间后缀解析，不凭市场猜时区；仅消费通过父子勾稽的明细行，不重复计算汇总。来源模式不能替代这一核验。

此格式成交额保留源符号（买入正、卖出负），按逐笔数量×价格×已匹配乘数核验，并按已核验币种的金额显示精度处理舍入。两个同名“交易费用”按原始列位置分别处理。空消费税保留未知，不能猜零；父子缺值模式一致时该组费用合计保持未知，净额继续受限。

computer-use 导出、用户手工文件和受限 native 采集分别记录为 `COMPUTER_USE_EXPORT`、`USER_ASSISTED`、`VERIFIED_DESKTOP`。CUA 回执和正式文件须在已验证的私人 `sources/` 中，无符号链接，导入时校验文件 hash、期间、时区、视图和有限动作。回执不是 GUI 执行或完整历史的机械证明，实际工具观察另作脱敏验收依据。`automatic_client_collection` 只标识已验证 native 采集，CUA 以独立 `collection_mode` 识别。

可选 native 定位入口为 `desktop-open`、`desktop-layout`。从新摘要中选择唯一 `eligible=true` 的固定导航候选，组装只含 `bundle_id/version/build/identity_hash` 的本地证明，再调用 `desktop-navigate --target account_nav --nav-proof <证明JSON>`；历史和账单类别分别为 `history/statement_nav`。表头同名候选不能使用。该入口不要求期间，不读取成交/日期、不导出或写入账本；期间选择仍是后续采集的必要输入。缺少可核验历史候选时继续 computer-use，不用原生适配开发替代普通页面导航。

`desktop-open` 可恢复已核验版本的唯一老虎业务窗口；仅激活应用不代表窗口已显示。最小化窗口无法通过点击命中检查时，先恢复窗口并重新取得布局与证明，不放宽命中条件。

自绘侧栏点击只支持已核验版本的账户入口；其他导航缺少已核验动作时保持拒绝。页面、版本或控件身份改变时重新取摘要，不能复用旧证明。失败须查看固定错误码及导航执行阶段；可能已经发出动作时先只读检查当前页，不盲目重试。没有取得历史页面及正式字段证据就不能声称采集成功。

如果正式成交视图的导出没有活动类型/成交ID列，只有在已确认其确为逐笔成交时才传 `--activity-type FILL`；委托视图应为 `ORDER`。日期/时区/页面身份未经确认就停在缺口，不通过补参数猜来源事实。辅助AX的佣金和含义未明的费用不当总费用；查询刷新与结果范围未确认时采集停止。采集动作、分页和AX/CSV转换hash另存私人来源回执。

重复来源 ID 去重，修改追加 revision；无 ID 的不同源文件不能靠同秒同价合并，疑似重复限制统计。费用、期初仓位、生命周期或乘数不完整时净盈亏/持有期可能不可计算。FIFO 只为复盘，多币种分开汇总。

覆盖状态中文含义：`PARTIAL` 实际来源或身份/期间仍有缺口；`SOURCE_COMPLETE_FOR_WINDOW` 仅证明所选来源窗口；`LIFETIME_RECONCILED` 还需可靠开户起点、全部类别与月份、分页终点及账单勾稽。手工导入始终保留人工来源模式。

图表完全本机离线，K线保留冻结行情口径。同日对应蜡烛只标B（仅买）、S（仅卖）、T（买卖都有）；字母只表示日期关联，不表示成交价，也不证明做T策略。悬停或点击固定蜡烛，在图内读取全部当天操作及相关事件。原始券商价格与期权权利金/完整合约独立展示，不改变标的价格轴。缺同日K或日期不确定时不标到邻日，完整操作仍可读取。

已有复盘可用 `review-reflection --report-id <已保存的reflection版本>` 生成或重新查看图表与全量复盘合并页；只读已保存版本，没有账户、行情或模型请求。标的/资产/合约/起止日期及可选年份快捷筛选关联实际成交引用，自选区间可以连续跨年。图表支持滚轮缩放、拖动平移和按钮重置，点击成交定位图表和明细，恢复全部后发现与练习不遗漏。已有原文要点与全部已存建议默认可读；目录、覆盖和详细来源默认折叠，重要局部限制紧随正文。当前图窗与已保存统计和复盘依据分别说明。返回的阅读路径供本机打开，原报告、旧中文报告和旧页面保留，新产物只改善阅读形式。

阅读页、展开详情、事件、提示、打印、中文报告及 Skill 交付文字使用业务标签，不显示 hash、内部 ID、私人路径、JSON 或技术代码。后台定位和源绑定仍用机器字段；公开网址、发布时间、金融数值、当时/事后/不确定层和真实缺口继续展示。

隔离失败不能通过传 synthetic 标志跳过。`prepare-clean-source` 仅供已授权开发/安装维护：锁定现用已审阅 baseline hash、只叠加两个 Skill 及支撑代码、保留其他产品内容，验证后才切换来源；普通使用不得自行更新插件或生产文件。

切换来源只产生 `SOURCE_VERIFIED`；真实写入仍禁止。安装维护再核验实际安装副本与洁净来源字节一致、私人合成哨兵未复制、旧基线可恢复，通过 `verify-installed-source` 才允许初始化。此后来源、安装副本或已审阅代码变化会重新阻断；不能手填 `VERIFIED` 代替实际核验。


## 持续本地工作区

```text
python3 <Skill路径>/scripts/journal.py --repo <绝对仓库根> serve-journal --account-ref <已有随机账户引用>
```

默认监听 `127.0.0.1:8765`，持续到启动终端按 Ctrl-C；不自动开机启动。需要其他端口时显式传 `--port`，不能静默换端口或关闭未知服务。单账户可省略账户参数，多账户必须明确选择。旧 `serve-review` 仍是固定复盘版本的短时只读入口。

- 刷新时间线：只重新读取完整已保存交易、行情和绑定正确的复盘，不读取券商、不联网、不调用模型。保留当前标的、资产、合约、起止日期、图窗与固定蜡烛阅读状态。
- 更新 K 线：显式读取有限公开行情，期权按标的去重，保存新子版本；部分失败保留相应旧有效行情。
- 导入新交易：选择官方逐笔成交 CSV、完整起止日期、导出日期范围时区及成交来源时区；混合美东/香港正式账单选择“按账单逐行明确时区”，普通单时区 CSV 选择其已核验时区，保存私人来源和完整历史新快照。相同文件重导不重复；无稳定成交编号的不同文件如日期/来源期间重叠，写入前拒绝，需不重叠导出或能证明成交身份的官方来源。仅当前启动账户可接收文件，不能混入其他账户。
- 生成新复盘：网页展示在 Codex 调用既有 Skill 的方法。当前会话 LLM 分析并保存后刷新，可从版本选择阅读；不创建网页模型后台。

最新交易图与每版复盘原图分别使用各自资料。当前选择不在旧研究内时明确说明，不能用旧结论评价新操作。版本菜单显示资料截止/保存时间；默认可读原文要点和全部改进练习，完整案例保留当时图表。hash 和私人路径仅留校验层。

上传保留原始文件字节，支持适配器已有的 UTF-8/BOM、UTF-16 和 GB18030 识别；不把文件先转成显示文字而改变原文件 hash。导入与全历史快照使用同一事务，失败时在释放写锁前清理此次新建来源，保留旧文件。

服务只提供固定查询与更新入口，Host、同源会话、写入证明、正文大小和单次更新门禁由本地进程检查。网页不能传任意路径、URL、SQL、账户、工具或模型参数。服务没有交易/账户写入能力。运行服务不改变此前浏览器工具访问拒绝；真实可视验收与虚构验证分开记录。
